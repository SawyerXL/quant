# CB 腿趋势过滤（CB 指数 MA200）— 预注册（2026-10-21，出数前锁）

> 核心优化候选：CB 腿是当前组合的主要收益引擎；本项检验**可转债市场自身的
> 趋势过滤**能否降低 CB 腿回撤/提升夏普。账本 **N=69**；判据出数前锁；
> 任何实装须另走参数变更三件套 + 用户确认。核心 40/60、15% 线不动。

## 1. 机制（先于数据）

可转债是股债混合资产，信用/流动性周期与正股趋势共同驱动；CB 指数跌破 MA200
时，资产类进入下行趋势（估值压缩/信用压力/赎回潮），双低策略的回撤集中在该段。
用 CB 指数自身趋势做**单腿仓位开关**（不是截面排序），与股票腿的 MA200 择时
同族但作用在 CB 资产类；机制=资产类趋势/信用周期，有制度根源（CB 市场流动性、
强赎/回售条款驱动的供给）。

## 2. 数据与口径

- CB 指数：`data_store/meta/cb_index.parquet`（2012-09-12~2026-10-16，close）。
- CB 策略 NAV：`logs/cb_eligibility_arms_nav.csv` 的 `nav_V3_N10`（V3 机制、
  TOP25 双低、2013-11-15~2026-09-18；与实盘 CB 腿同机制）。
- 现金：`CASH_YIELD`（来自 `run_backtest_a`，与回测一致）；换手成本
  **0.1%/次**（CB 双边成本，`REAL_COST`）。
- 信号：t−1 收盘 CB 指数 close > MA200（200 交易日）→ t 日持有策略；
  否则持有现金。无前视（shift 1）。
- 主口径：**日频信号**；诊断：月末信号（下月生效）、半仓（0.5）、MA100/MA250。

## 3. 判据（全部满足才 PASS）

1. 夏普：overlay ≥ base **+0.05**；
2. 最大回撤：overlay 比 base 改善 **≥2.0pp**；
3. 年化：overlay ≥ base **−1.0pp**（允许小幅让收益）；
4. OOS 2019-2026：夏普 ≥ base，且回撤改善 ≥1.0pp；
5. 开关次数 ≤60（非高频来回）。

任一条不过 → 不实装；不调 MA 窗口/成本/信号频率（诊断项不入判据）。

## 4. 盲区

1. CB 指数与策略 NAV 的编制口径不同（指数 vs TOP25 双低组合）；信号只表征
   资产类趋势，非策略自身净值。
2. 2013-2018 数据/指数质量未逐日审计；CB 退市/停牌在指数中的处理未知。
3. 现金收益用回测常数，实盘货基/短债收益可能不同。
4. 日频信号的实际执行=下一交易日收盘/次日开盘；本回测用日收益，未建日内先后。
5. 趋势过滤与股票腿 MA200 可能同向（CB 与正股相关），组合层增益需另测。
6. 实装须重跑三件套并按参数变更纪律 A/B；本项只判断“是否值得进入实装流程”。
