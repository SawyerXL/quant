# 成本模型审计（2026-10-21）

> 触发：券商/手续费研究。核心问题=回测的成本假设 vs 实际费用，以及
> 它对收益率/校准的影响。**本文件不改变任何策略参数；成本口径修正后
> 才谈重跑。**

## 1. 回测成本 vs 实际费用

- 引擎 `backtest_config.commission = 0.0013`（**13bp/边**；注释
  "双边(佣金+印花+滑点)"）。引擎在每次交易按 `config.commission` 计，
  买卖两侧各一次 → **往返 26bp**。
- `logs/exec_cost_audit_20261020.md` 的 "0.33% 双边成本" = **33bp 往返**，
  与引擎的 26bp 并存——**两个口径需要统一**（0.33% 更保守）。
- 实际（2026-10-21 公开/协商费率，见券商研究答复）：
  - 股票：佣金万1~万1.5 + 卖出印花税**万5** + 过户万0.1；小单最低5元
    （≈2.5bp/边）。
  - **往返约 10~12bp**（不含冲击/滑点）；加 1~3bp/边滑点 → **12~18bp**。
  - CB：万0.5 + 沪最低1元/深0.1元，往返约 **1~2bp**（不含滑点）。
- 若 13bp/边 的"双边"是**往返**语义，引擎按边收 = 高估约 **10~14bp/往返**。
  年化（股票腿）：`A_TURNOVER 9.03x × 10~14bp ≈ 0.9~1.3%/年`；
  40/60 股票权重40% → **0.4~0.5%/年**的保守偏差。
- **但滑点/冲击未实测**（策略单样本 0/100），**不得把上修记账**；
  回测 12.54% 是偏低的下界，实际可能 ~12.9~13.0%，等真实成交确认。

## 2. A/C 18bp 与成本配置

- `measure_execution_costs` 的 18bp = A/C 交叉阈值（2026-09-06 钉死）；
  其成本定义用 `COMMISSION_RATE 万2.5 + STAMP_TAX 千1`。
- 实际：佣金可谈万1~万1.5（非万2.5）；印花 **万5**（非千1）→ 定义
  **高估约 6~7bp**（万1.3 佣金 + 5bp 印花差）。
- 影响：实测成本被高估 → 更容易 >18bp → 倾向"切C"；修正后 A/C 交叉
  需**重推导**（判据先锁；阈值未改）。
- 当前盲盒样本 **0/100**，尚未裁决；真实成交后再定。

## 3. 对策略结论的影响

- 成本保守 → 回测净收益偏低、夏普/回撤略偏保守（成本计入 NAV）。
- 40/60、卫星、被动化、50/50 的**相对排序不受影响**（同引擎/同 commission）；
  绝对水平可能上修 0.4~0.5pp（40/60），但**只在真实成本确认后才可写入
  部署期望**。
- 15% 线：成本下修略微改善收益/回撤，**不改线**。

## 盲区

- 佣金/最低收费是**协商结果**，以交割单为准；公开资料仅供参考。
- 滑点/冲击取决于订单规模、时点、市场状态；当前无真实成交样本。
- 引擎的 13bp 语义（单边 vs 往返）以代码为准：`port_rets -= w*commission`
  在买卖两侧各执行一次 → 往返 2×13bp；注释"双边"与此存在措辞冲突，
  本文按代码行为判读。
