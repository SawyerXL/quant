# 涨跌停闸 P1 参数三件套预登记（2026-10-01 出数前锁）

> 变更对象：引擎 `limit_gate` 默认 False → True（代码 01b43f6 已实装，测试 4/4，
> 零行为变更默认关）。启用时点=节后批（10-09 受控实验后），与现金 1.4% 同批
> 一次重跑；本登记先于出数，出数后不得修改。

## 一、事前预测登记（含错误风险）

1. **年化方向：不预设符号**。机制双向：涨停禁买移除"买涨停票"的乐观假设（回测
   按收盘价成交、实盘买不进——预期偏负）；但跳过的涨停票若次日回落，跳过也是
   避损（偏正）。**预测：|Δ年化| < 0.5pp，符号不定**——这本身是预登记的一部分：
   若 |Δ| > 1pp 且方向单一，先怀疑归因而非"效果大"。
2. **触发计数：预期显著非零**（pool30 热门票池涨停概率高于 800 等权；每次调仓
   30 只预计 0~2 只触板）。**计数 = 0 → 不是"无效果"，是实现 bug 或判据失效
   （0 触发=未验证纪律）→ 先查再谈。**
3. **换手：略降**（涨停买入跳过不重归一=现金拖累；轮出遇跌停顺延=少一次卖出）。
4. **回撤：方向不定**（跌停顺延可能避过极值卖出价，也可能顺延到更低价格）。

## 二、判读矩阵（出数前锁）

| 出数 | 判读 | 处置 |
|---|---|---|
| 触发计数 = 0 | 判据失效或实现 bug | 查实现/判据，不启用 |
| \|Δ年化\| < 0.5pp | 与预测一致，保真修正成立 | **启用**——注意：启用理由是正确性不是效应（回测必须描述实盘可达的东西），即使 Δ 为负也启用 |
| 0.5 ≤ \|Δ年化\| < 1pp | 超出预测但量级仍小 | 归因检查后启用；归因不过则停 |
| \|Δ年化\| ≥ 1pp | 预测外，单一方向 | **先查归因（闸门三）**：涨停票"次日回落"是否被跳过/顺延放大？触发是否异常集中？归因不过 → 不启用，回滚 |
| 回撤变化 > 2pp | 顺延路径可能积压 | 归因跌停顺延的时间分布，确认无"越顺延越深"循环 |

## 三、归因闸门（表面大优/大劣时强制）

1. **事件集中检查**：Δ 改善/恶化是否集中于 ≤2 个事件期（如某次极端行情）——
   集中 → 事件归因，不读作结构效应（五档-更早降档的 09-21/22 归因先例）。
2. **触发时间分布**：涨跌停密集期（2015-08/2024-09/2026-02 类）的触发计数与
   贡献分解；若 Δ 主要来自单一段，标记"待更长样本"。
3. **与现金 1.4% 的分开归因（同批顺序）**：
   - 第一层：基线 vs 1.381 = **纯漂移**（进漂移日志第 3 行，门槛规则实战）
   - 第二层：现金 1.4% = **算术级可预测**（熊档闲置收益降，方向确定）——实测
     与算术预测对照，偏差超 0.1pp 查实现
   - 第三层：limit_gate = **残差归因对象**——行为修正，按本矩阵判读
