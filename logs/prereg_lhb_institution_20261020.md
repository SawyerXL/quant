# 龙虎榜机构净买入后漂移 — 预注册（2026-10-20，出数前锁）

> 新假设，账本 **N=67**；机制=**信息披露后的机构资金流**（结构性资金流合格类）。
> 判据先锁；OOS 仅一次；不调阈值/窗口；核心 40/60 与 15% 线不动。

## 1. 机制（先于数据）

龙虎榜在收盘后披露（交易所制度），机构专用席位的净买入反映当日大额/机构资金方向；
散户关注度与跟风在次日及之后形成正漂移（注意力 + 资金流延续）。与 R1 涨停板
博弈的区别：**入场在 T+1 开盘，可执行**；与“成交额排序轴”的区别：信号是
披露的机构净买额（信息事件），不是历史成交量排名。

## 2. 数据与事件定义（冻结）

- 数据：akshare `stock_lhb_jgmmtj_em`（机构专用席位买卖汇总），2019-01-01~2026-10-19，
  按季度抓取；只保留 6 位股票代码（剔除转债/基金）。
- 事件日 = `上榜日期`；事件日收盘后信息已知 → **T+1 开盘入场**。
- 主事件：`机构买入净额 > 0` 且 `机构净买额占总成交额比 ≥ 1.0%`（材料级）。
- 去重：同一股票 20 个交易日内多次上榜，只保留第一条。
- 剔除（计数）：ST/上市<60 日/缺 bar/入场日开盘涨停/出场日收盘跌停/
  窗口 |日跳|>50%。
- 入场：事件日后首个交易日开盘；出场：入场后第 20 个交易日收盘；60 日仅诊断。

## 3. 收益与统计（冻结）

- 事件收益 = close(X)/open(E) − 1；基准 = 同窗等权买入持有；超额 = 收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 日聚类 t（按入场日）；t_stock 诊断；均值/中位/胜率。
- IS 2019-2022；OOS 2023-2026（OOS 仅一次）。
- MDE = 2.8×日聚类 SE，按实测重算并先行披露。

## 4. 判据（方向=正，全部满足才 PASS）

1. 净超额均值 >0 且日聚类 **t ≥ 2.5**；
2. OOS 同号且日聚类 **t ≥ 1.5**；
3. N ≥ **500** 事件且 ≥ **200** 个入场日；
4. 均值 ≥ MDE 且 ≥ 0.33% 成本。

任一条不过 → 关闭；不调阈值（1%）、窗口（20 日）、去重（20 日）。

## 5. 诊断（不入判据）

- 阈值 3% 分层；机构家数（买方机构数 ≥2）；60 日；分年。
- 与 R1/减持/N=59 的重叠审计（若事件层 PASS，再决定是否做组合层 overlay；
  注意 N=52/60 教训：事件层 PASS ≠ 组合层增益）。

## 6. 盲区

1. 龙虎榜是“异动股票”的选择样本（涨停/换手/振幅），事件与动量混杂；
   本项只测披露后的可执行漂移，不做因果归因。
2. “机构专用”可能是量化/游资通道，不等于长期机构；无法识别真实意图。
3. 数据源为第三方汇总；字段口径（净买额/占比）未与交易所原始表逐笔核对。
4. 2019-2026 制度与披露规则可能变化；单一市场。
5. 20 日窗口固定；不测更短/更长。
6. 若事件层 PASS，组合层仍可能因重叠率低而无效（历史两例）。
