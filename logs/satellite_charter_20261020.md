# 高波动卫星账户 — 章程（2026-10-20，用户授权"核心不动+高风险卫星"）

> 用户 2026-10-20 在"64% 目标"下选择：**核心 40/60 不动、守 15% 回撤；
> 另设 10%~20% 资金的独立高波动卫星，明确可能大亏甚至归零。**
> 本文件=卫星的执行边界；**卫星的任何仓位不改变核心的红线与配置**。

## 1. 资金与隔离（硬约束）

- 卫星资金：**20 万**（160 万总盘的 12.5%，在用户 10%~20% 授权区间内；
  用户可调整，但不得超过 32 万）。
- **必须独立账户/独立台账**：核心 QMT 账户的主链（14:30 compute_plan/止损/做T）
  会对账户全部持仓动作；卫星若同账户会被主链卖出/覆盖（R1b 同款教训）。
  在独立账户就绪前，卫星只做**研究 + 模拟台账**，不投真钱。
- 卫星最大损失=卫星本金；核心的 15% 账户线**只按核心账户计算**，不含卫星。
- 禁止：卫星与核心互相补仓/搬钱；卫星亏损触发核心减仓；用核心持仓做卫星担保。

## 2. 卫星目标与风险声明

- 目标：**高波动、非对称收益**，争取单年高回报；**不承诺 64%**。
- 可接受：单年 −50%~−100%（归零）为合法结果；不设"必须赚回来"的补仓规则。
- 与核心的关系：相关性尽量低（卫星优先选核心没有的暴露：期货基差、期权凸性、
  高波动事件）；不得把核心的股票/CB 仓位复制一遍加杠杆（=伪分散）。
- 杠杆：卫星内允许，但**总名义敞口 ≤ 卫星本金的 3 倍**；保证金不足即减仓，
  禁止追加核心资金。

## 3. 候选策略（按优先级；每个都走预注册）

1. **股指期货吃贴水（IC/IM/IF/IH）**：结构性对冲贴水；N=44 已有锁定判据
   （`scripts/backtest_futures_basis.py` docstring），MDE 已过（IC 1.86pp/
   IM 4.02pp/IF 1.50pp/IH 1.42pp ≤5%）；全量测试中。
   若通过：卫星可用 2~3x 名义敞口吃基差；风险=指数下跌+基差反向+保证金。
2. **ETF 期权凸性**：熊市买远月虚值 Put（尾部保护/凸性）、政策催化买 Call；
   权利金=最大损失；需期权账户（50 万门槛/考试）与历史数据审计。
3. **CB 激进子策略**：高收益/双低/条款博弈的集中版本；共用 CB 数据链
   （不引股票日线）；与核心 CB 腿的相关性需测，避免重复暴露。
4. **高波动事件策略**：只在有新的结构性机制时立项；R1/指数调仓/解禁/
   大宗 overlay 已失败，不重复。

## 4. 流程（每个候选）

1. 预注册：机制、数据、事件/信号定义、执行时点、成本、MDE 先行、判据先锁。
2. 回测：OOS 只用一次；成本敏感性；与核心两腿的相关性/正交性。
3. 模拟/前向：≥3~6 个月（或≥60 个事件）的真实/仿真成交记录；不达标不投真钱。
4. 实盘：独立账户、独立台账；单笔/单策略上限按卫星本金；月度复盘。
5. 停止规则：卫星回撤 ≥50% → 暂停新开仓并人工复核；连续 3 个月负超额 →
   降规模或关闭；任何"加仓摊平"禁止。
