## 2. 18bp A/C 规则为何作废（不是重推导）

- 旧公式：`18bp = 13bp + 0.26pp/5.54 = 17.7bp`，前提是 A≈C 打平、A 在
  13bp 时领先 0.26pp。
- **旧四臂表本身**：等风险 A +4.43% / C +4.69%（A 落后 0.26pp @13bp）
  ——与公式符号矛盾（同一 0.26pp，方向相反）。
- **更关键：旧四臂表已被 2026-09-07/08 判作废**——它是污染池上测的。
  修正数据（spec §6.9 ⑪/⑫）：
  - **A（完整栈/现网）= +7.07% / 夏普 0.65 / 回撤 −11.2%（全表最优）**
  - B = +3.99%；**C（完整栈−MA10）= +7.30% / 0.48 / −23.5%**；D = +6.59%
  - C 的年化略高 0.23pp，但回撤深 **12.3pp**；等风险缩放后 A 更优，
    **切 C 不是无代价选项**。
- 因此：**18bp 不再作为裁决线，也不重推导**。`measure_execution_costs`
  保留为**成本校准**（实测单边等效、滑点/费用分解），不再输出"切C/维持A"。
  当前策略单 0/100，盲盒继续。
