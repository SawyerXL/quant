## 1. 规则（冻结）

- 事件：机构龙虎榜净买入（机构净买额/成交额 ≥1%，净额>0），同股 20 交易日去重。
- 回避：调仓日 R 前 **1~20 个交易日**内有事件的**非持仓候选**不买，下一名补位；
  已持仓不强制卖（与 N=60 同口径）。
- 引擎：`apply_filters(exclude,held)` / `run_backtest(exclude_map)`（默认 None 行为不变）。
- 主画像：50 万/组、lot=100；对照：无约束（lot=0）。
- 全期 2019-01-01~2026-10-19；分段 OOS 2023-01-01~2026-10-19（**复用**，非新 OOS）。

## 2. 判据（全部满足才 PASS，仅“进入前向纸面验证”）

1. 50 万/组 Δ年化 ≥ **+0.50pp**；
2. 夏普不低于基线；最大回撤不差于基线 **0.5pp**；
3. OOS 段 Δ年化 ≥0 且不劣化回撤；
4. 月度差 bootstrap **t ≥ 1.0**（1SE）；
5. 无约束对照 Δ年化 ≥ −0.20pp（不得只靠 lot 约束造出效应）。

任一条不过 → 关闭；不调窗口（20 日）/阈值（1%）。

## 3. 已知重叠（先于收益）

  被回避 **334（6.06%）**，149/186 个调仓日有重叠，单日最多 7 只。

  overlay 值得一测；但事件后补位的下一名也可能同属高换手/注意力股。

## 4. 盲区与部署限制

1. **方向事后、OOS 复用**：本项不是独立确认；即使 PASS 也只能进入**前向纸面**
   （≥3 个月/≥6 个调仓周期），不得直接改核心。
2. 事件样本为“异动股票”，与动量/小市值/风格混杂；回避的收益可能来自风格而非机制。
3. 引擎日程=双周（历史口径），实盘为月中/月末；结论需在实盘日程上复跑。
4. 补位下一名未必中性；容量/流动性未建模。
5. 数据源为第三方龙虎榜汇总；未与交易所原始披露逐笔核对。
