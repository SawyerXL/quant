# 新 edge 候选：溢价大宗交易后的正漂移（premium-block）— 预注册（2026-10-20 11:3x，出数前锁）

> 用户要求"找方式支撑提升年化"。已 FAIL：PEAD、增持、减持 overlay。本候选=
> **溢价大宗交易**（买方高于市价接货）后的 5 日正漂移。**本文件在计算事件收益前
> 写定；判据不再改。** 账本 N=61。

## 1. 机制（先于数据）

大宗交易通常是折价（买方要流动性补偿）。**溢价成交**相反：买方愿意**高于市价**
接大额筹码，说明其**急迫/掌握正面信息/战略意图**（如举牌、并购、产业资本增持）。
A 股大宗交易制度（盘后协议、最低门槛、减持规则）是制度根源；散户对大宗溢价
关注不足 → 后续正漂移。方向=正（长仓可执行）。

## 2. 数据（已审计）

- `data_store/meta/block_trade_events_2019_2026.parquet`（as_of=2026-10-19，
  120,130 行）+ `block_trade_events_2015_2018.parquet`（OOS）。
- 字段：交易日期/成交价/成交总量(万股)/成交总额(万元)/折溢率/成交总额/流通市值。
- 已核：`成交总额=成交总量×成交价`（p99 误差 0.03%）；折溢率=成交价/收盘−1；
  与 MCP 跨源逐字段一致。
- 事件日 T=交易日期；T+1 开盘为可执行入场（数据盘后发布）。

## 3. 事件定义（冻结）

- **主事件：折溢率 ≥ +5%**（明确溢价；单一阈值，不网格）**且 成交总额/流通市值
  ≥ 0.5%**（材料级成交）。
- 去重：同一股票 5 个交易日内多次溢价大宗，只保留第一条。
- 样本：2019-01-01~2026-09-30（主窗）；OOS 2023-2026；2015-2018 仅诊断。
- 剔除：ST/上市<60/缺 bar/E 开盘涨停/X 收盘跌停/窗口 |日跳|>50%（计数）。

## 4. 执行与收益（冻结）

- 入场 E=T+1 开盘；出场 X=E+4 收盘（**5 个交易日**，含入场日）；
  20 日窗口仅诊断。
- 事件收益=`close(X)/open(E)-1`；基准=同窗等权买入持有；超额=收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 统计：按入场日聚类 t；均值/中位/胜率；t_stock 诊断。

## 5. 判据（出数前锁，方向=正）

- **通过需全部满足**：
  1. 主事件净超额均值 **>0** 且日聚类 **t ≥ 2.5**；
  2. OOS 2023-2026 同号且日聚类 **t ≥ 1.5**；
  3. N ≥ **200** 事件、≥ **100** 个入场日（溢价样本比折价小，门槛下调）；
  4. 均值 ≥ **MDE**（2.8×日聚类 SE，按实测重算）且 ≥ 0.33% 成本。
- 判定：全过 → "溢价大宗正漂移候选"，进入组合/容量/前向验证；任一条不过 →
  关闭；不调阈值/窗户/去重规则。
- 诊断（不入判据）：20 日、+3%~+5% 次级、分年、市值/流动性分层。

## 6. MDE 先行（未看事件收益）

- 参考 block 全量 5 日 SD 6.8%；溢价子集可能更高（12~18%）；N 预计 500~2,000、
  入场日 200~600；日聚类均值 SE ≈ 0.5~1.2%；**MDE(2.8×) ≈ 1.4~3.4%**。
  正式出数用本样本日聚类 SD 重算；若 MDE >3%，结论=不可判读。
- 经济门槛：成本 0.33% 双边；净超额须 ≥MDE。

## 7. 多重检验与盲区

- 账本 **N=61**；近期 PEAD/增持/减持/指数调仓/解禁/期权 VRP 均未过组合层；
  本项是新假设，判据先锁、OOS 仅一次。
- 盲区：
  1. 溢价大宗可能含**关联方对倒/过桥/利益输送**（高价成交非市场化），信号可能
     是噪声；报告成交笔数/买方营业部特征（数据有买卖方字段的期间）。
  2. 大宗日汇总是聚合值（多笔不同价被平均）；溢价可能是个别笔拉高。
  3. 样本小（溢价稀有）；OOS 事件更少，统计功效有限。
  4. 同窗等权基准未做市值/行业中性；结果须报画像。
  5. 20 日仅诊断；不得事后换窗。
