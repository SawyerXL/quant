# 新 edge 候选：重要股东减持后的负漂移/回避（shareholder-decrease）— 预注册（2026-10-20 11:1x，出数前锁）

> 用户要求找新 edge；PEAD（N=57）与增持（N=58）均 FAIL。本候选=**重要股东
> 减持公告后的 20 日负漂移**，落地形式=**回避规则**（A 股不能稳定做空）。
> **本文件在计算事件收益前写定；判据不再改。** 账本 N=59。

## 1. 机制（先于数据）

重要股东（控股股东/大股东/董监高）二级市场**减持**=**供给冲击 + 知情卖出**：
减持人掌握内部信息、在股价强势时卖出（卖在强势）；A 股减持须公告披露（制度根源），
散户有限关注/反应不足 → 公告后 20 日存在**负漂移**。与增持（护盘/困境信号）相反，
减持是**主动卖出**，方向预测=负。

## 2. 数据（已审计）

- `data_store/meta/shareholder_changes.parquet`（as_of=2026-10-20，147,114 行；
  减持 **113,266** 行；2019-01-01~2026-09-30 子集）。
- 字段：代码/名称/股东名称/增减/变动数量/占总股本比例/变动开始日/变动截止日/公告日。
- PIT：事件日=**公告日**；T+1 开盘为最保守可执行时点。
- 宇宙：本地日线，非 ST、上市≥60 日、正价、窗口 |日跳|≤50%。

## 3. 事件定义（冻结）

- 方向：**减持**（`持股变动信息-增减 == "减持"`）。
- **主事件集：重要股东减持**——股东名称含公司/集团/控股/投资/合伙类字样，
  排除基金/资管/信托/证券/保险/银行/计划等产品账户；同一 (股票, 公告日) 取
  **占总股本比例最大**的一条。
- **规模门槛：占总股本比例 ≥ 0.10%**（材料级减持；单一阈值，不网格）。
- 去重：同一股票 20 个交易日内多次减持公告，只保留**第一条**（避免重叠窗口）。
- 次事件集：全部减持（含个人/小额，诊断）。
- 剔除：公告日 >2026-09-30；ST/上市<60/缺 bar/E 开盘涨停/X 收盘跌停/窗口脏跳。

## 4. 执行与收益（冻结）

- A=公告日；E=A 之后首个交易日开盘（非交易日顺延）；X=E+19 交易日收盘
  （20 个交易日含入场日）；60 日仅诊断。
- 事件收益=`close(X)/open(E)-1`；基准=同窗等权买入持有；超额=收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 统计：按入场日聚类 t；均值/中位/胜率；t_stock 诊断。

## 5. 判据（出数前锁，方向=负）

- **通过需全部满足**：
  1. 主事件净超额均值 **<0** 且日聚类 **t ≤ −2.5**；
  2. OOS 2023-2026 同号（<0）且日聚类 **t ≤ −1.5**；
  3. N ≥ **500** 事件、≥ **200** 个入场日；
  4. |均值| ≥ **MDE**（2.8×日聚类 SE，按实测重算）且 ≥ 0.33% 成本。
- 判定：全过 → "减持负漂移/回避候选"；落地形式=**从 pool30 买入中回避**
  （事件后 20 个交易日不新买），组合层 overlay 另立预注册；任一条不过 → 关闭；
  不调阈值/窗户/股东类型去救。
- 诊断（不入判据）：60 日、个人/小额减持、分年、市值/流动性分层。

## 6. MDE 先行（未看事件收益）

- 参考同类事件：20 日事件超额 SD 约 12~18%；主事件 N 预计 5,000~15,000、
  入场日 800~1,500；日聚类均值 SE ≈ 0.3~0.6%；**MDE(2.8×) ≈ 0.8~1.7%**。
  正式出数时用本样本日聚类 SD 重算并报告。
- 经济门槛：成本 0.33% 双边；|均值|须 ≥MDE 才有回避意义。

## 7. 多重检验与盲区

- 账本 **N=59**；PEAD/增持/指数调仓/解禁/大宗/期货贴水/期权 VRP 均未过；
  本项是新假设，判据先锁、OOS 仅一次。
- 盲区：
  1. 公告滞后：减持可能已完成才公告（公告后是"卖完"也可能是"继续卖"的
     信号）；事件收益从 T+1 开盘计，已发生的卖出不计入。
  2. 股东名称解析启发式；产品账户误分类风险；报告分类计数。
  3. 同一股东连续减持、多股东减持：20 日去重只保留首条，可能低估总供给。
  4. 减持样本自选择（强势时减持）；事件内漂移才是检验对象。
  5. 同窗等权基准未做市值/行业中性；结果须报市值/流动性画像。
  6. 20 日窗口；60 日仅诊断；不得事后换窗。
