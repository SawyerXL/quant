# 散户“低吸5绝招”日线可测子集 — 证伪检验（2026-10-20 14:2x，出数前锁）

> 用户提供“精准低吸5大绝招”，要求研究能否提升年化。本文件只检验**日线可测**部分，
> 判据先锁；L2 盘口部分无历史数据，列为不可测盲区。性质=证伪类（同 N=44 MACD），
> 不占 alpha 预算；账本 N=63。

## 1. 机制与先验

- 主张：长期横盘（≥4个月）+ 低位低价 + 红肥绿瘦（吸筹）+ 单阳不破 → 后续上涨。
- 机制解释：长期横盘后筹码集中，突破/异动吸引注意力资金；A股散户注意力与
  涨停制度放大。**但属技术形态族**，项目已有证据（量比无预测力、成交额排序轴
  负 alpha、MACD 证伪）给出低先验。
- 本检验目的：按用户要求**可复现地测量**，而非默认采纳。

## 2. 事件定义（冻结，主检验）

四项同时满足，首次触发：

1. **低位**：close 位于过去 250 日收盘区间下 30%（(close−min)/(max−min) ≤ 0.30）。
2. **横盘≥4个月**：过去 80 交易日 max(close)/min(close)−1 ≤ 20%，且
   |close/close[t−80]−1| ≤ 10%。
3. **红肥绿瘦**：过去 80 日上涨日成交量之和 ≥ 1.5×下跌日成交量之和。
4. **单阳不破**：过去 20 日内出现过单日涨幅 ≥5% 的大阳线，且自该日起至今日
   收盘从未跌破该日最低价。

- 数据不足 250 日、ST、停牌缺 bar 的股票剔除。
- 同一股票 20 交易日内的重复触发只保留第一条。
- 买入：事件日 T+1 开盘；卖出：入场后第 20 个交易日收盘；60 日仅诊断。
- 剔除（计数）：入场日开盘涨停、出场日收盘跌停、窗口 |日跳|>50%。

## 3. 收益与统计（冻结）

- 事件收益 = close(X)/open(E)−1；基准 = 同窗等权买入持有；超额 = 收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 日聚类 t（按入场日）；t_stock 诊断；均值/中位/胜率。
- 分段：IS 2019-2022；OOS 2023-2026（OOS 仅一次）。
- MDE：2.8×日聚类 SE，按实测重算，先行披露。

## 4. 判据（方向=正，全部满足才 PASS）

1. 净超额均值 >0 且日聚类 t ≥ 2.5；
2. OOS 同号且日聚类 t ≥ 1.5；
3. N ≥ 500 事件且 ≥200 个入场日；
4. 均值 ≥ MDE 且 ≥ 0.33% 成本。

任一条不过 → **关闭该族**；不调阈值/窗口/去重规则。

## 5. 诊断（不入判据）

- 分项：A（低位）、A+B（低位+横盘）、A+B+C（+红肥绿瘦）、A+B+C+D（主检验）。
- 低价分层：close ≤ 10 元 vs >10 元。
- 60 日窗口；分年。
- **9:45 / 14:30 入场**：需分钟数据；现有 5 分钟库仅覆盖持仓票近 40 日，
  样本不足，**本轮不测**（不得据传闻采纳）。
- **盖板/托板/隐形盘/内外盘**：需 L2 逐笔委托历史，本地无数据，**不可测**；
  不进入策略。若要做，只能前向采集 QMT tick 数月后再议。

## 6. 盲区

1. 形态为事后可见定义；参数（30%/20%/10%/1.5×/5%）一次锁定，不网格。
2. 红肥绿瘦用日线成交量近似主力吸筹，无法区分对倒/量化。
3. 同窗等权基准未做行业/市值中性；结果须报画像。
4. 20 日持有；不测更短/更长窗口。
5. L2 与日内时点不可测（见 §5）。
