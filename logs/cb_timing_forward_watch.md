## 诊断（2026-10-21，非新假设）

- **逐年归因**：基准最大回撤 −21.24% 发生在 **2024**（双低凶手年）；nav_yi overlay
  的 2024 回撤 −8.04%，**单年改善 +13.2pp**；其余年份 2020 +1.4 / 2021 +4.1 /
  2026 +1.6 / 2023 −0.3 / 2019/2022/2025 0。**改善高度集中于 2024 一个事件**
  （归因闸门：≤2 个事件的表面大优须谨慎）。
- 分段：P1 2019-2022 overlay 20.14%/2.05/−10.21% vs base 20.76%/1.996/−11.53%
  （小幅）；P2 2023-2026 overlay 8.16%/1.019/−10.56% vs base 9.49%/0.84/−21.24%
  （Sharpe 改善主要来自 2024）。
- V3 自身 NAV MA200（自计时）：13.57%/1.55/−13.14%，P2 6.89%/0.917/−12.82%，
  弱于 nav_yi 同胞；但实盘可直接用自身 NAV，实施更简单。
- **组合层（关键）**：
  - 40/60：base 11.25%/1.137/−14.15% → yi overlay **10.63%/1.165/−8.99%**
    （年化 −0.62pp、夏普 +0.028、DD +5.16pp）；
  - **62.5/37.5（=实盘 100/60 名义）**：base 8.89%/0.831/−12.77% →
    yi overlay 8.50%/0.816/−12.80%——**无改善**。
  - 结论：overlay 的组合价值**取决于配比**；实盘当前 100/60 名义口径下看不到增益，
    40/60 配比下 DD 才明显改善。**40/60 vs 100/60 的口径差是待裁定的配置问题，
    本观察不改变实盘配比。**
- 因此前向纸面**同时记录**：信号、CB 腿 overlay、40/60 与 62.5/37.5 两种组合。
