# 新 edge 候选：重要股东增持后的漂移（shareholder-increase）— 预注册（2026-10-20 11:1x，出数前锁）

> 用户要求找新 edge；PEAD-forecast（N=57）已 FAIL。本候选=**重要股东/控股股东
> 增持公告后的 20 日漂移**。**本文件在计算事件收益前写定；判据不再改。**
> 账本 N=58。

## 1. 机制（先于数据）

重要股东（控股股东/大股东/董监高）在二级市场**自愿增持**是**昂贵的信息信号**：
内部人用自己的钱买入，表明其对公司价值的判断；A 股增持须公告披露（制度根源），
散户有限关注/反应不足 → 公告后 20 日存在正漂移。与"排序轴"无关：事件是制度化
的公开披露 + 内部人行为，不是"历史涨得好"的排序。

## 2. 数据（审计中）

- 来源：akshare `stock_ggcg_em(symbol="全部")`，约 147k 行；字段含
  代码/名称/股东名称/增减/变动数量/占总股本比例/变动开始日/变动截止日/**公告日**。
- **PIT**：事件日=**公告日**（公开披露日）；增持可能发生在公告前后，但信号在
  公告日公开；T+1 开盘为最保守可执行时点。公告日盘后发布→T+1 开盘；若盘中
  发布，T+1 开盘已含当日反应（保守）。
- 宇宙：本地日线，非 ST、上市≥60 日、正价、窗口 |日跳|≤50%。

## 3. 事件定义（冻结）

- 方向：**增持**（`持股变动信息-增减 == "增持"`）。
- **主事件集：重要股东增持**——股东名称含公司/集团/控股/投资类字样
  （"有限公司/集团/控股/投资/合伙"），排除"基金/资产管理计划/信托/证券"等
  产品账户；**同一 (股票, 公告日)** 多行取**占总股本比例最大**的一条。
- **规模门槛：占总股本比例 ≥ 0.10%**（材料级增持；单一阈值，不做网格）。
- 去重：同一股票 20 个交易日内多次增持公告，只保留**第一条**（避免重叠窗口）。
- 次事件集：全部增持（含个人/小额，诊断，不入主判据）。
- 剔除：公告日晚于 2026-09-30 的（20 日窗口不完备）；ST/上市<60/缺 bar/
  E 开盘涨停/X 收盘跌停/窗口脏跳，全部计数。

## 4. 执行与收益（冻结）

- A=公告日；E=A 之后首个交易日开盘（A 非交易日则顺延）；X=E+19 交易日收盘
  （20 个交易日含入场日）；60 日窗口仅诊断。
- 事件收益=`close(X)/open(E)-1`；基准=同窗等权买入持有（全宇宙）；
  超额=事件收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 统计：按入场日聚类的日均超额 t；事件级均值/中位/胜率；t_stock 作诊断。

## 5. 判据（出数前锁）

- **通过需全部满足**：
  1. 主事件全样本净超额均值 **>0** 且日聚类 **t ≥ 2.5**；
  2. OOS 2023-2026 同号且日聚类 **t ≥ 1.5**；
  3. N ≥ **500** 事件、≥ **200** 个入场日；
  4. 均值 ≥ **MDE**（2.8×日聚类 SE，出数时按实测 SD 重算）且 ≥ 0.33% 成本。
- 判定：全过 → "增持漂移候选"，进入组合/容量/前向验证，不直接部署；
  任一条不过 → 关闭；不调阈值/窗户/股东类型去救。
- 诊断（不入判据）：60 日、个人/小额增持、分年、市值/流动性分层。

## 6. MDE 先行（未看事件收益）

- 参考同类事件（预告/大宗）：20 日事件超额 SD 约 **12~18%**；
  事件 N 预计 2,000~6,000、入场日 500~900；日聚类均值 SE ≈ 0.4~0.7%；
  **MDE(2.8×) ≈ 1.1~2.0%**。正式出数时用本事件样本的日聚类 SD 重算并报告。
- 经济门槛：成本 0.33% 双边；净超额须 ≥MDE 才有部署意义。

## 7. 多重检验与盲区

- 账本 **N=58**；近期 PEAD/指数调仓/解禁/大宗/期货贴水/期权 VRP 均未过；
  本项是新假设，判据先锁、OOS 仅一次。
- 盲区：
  1. **公告日 vs 实际增持日**：增持可能已完成才公告（公告滞后），事件收益
     从 T+1 开盘计，已发生的买入不计入；反而更干净（公告后的反应）。
  2. 股东名称解析为启发式；"投资/合伙"可能是产品账户，误分类风险；结果须
     报告分类计数与样本示例。
  3. 同一股东连续增持、同一股票多股东增持：20 日去重只保留第一条；其余丢弃，
     可能低估总信号。
  4. 增持样本自选择（公司/股东在看好时增持）；事件内漂移才是检验对象。
  5. 同窗等权基准未做市值/行业中性；结果须报市值/流动性画像，部署前加中性对照。
  6. 20 日窗口；60 日仅诊断；不得事后换窗。
