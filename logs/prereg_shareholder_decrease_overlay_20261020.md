# 重要股东减持回避 × pool30 — 组合层 overlay 预注册（2026-10-20 11:2x，出数前锁）

> 来源：N=59 事件层 **PASS**（重要股东减持后 20 日净超额 −0.514%/t_day −2.90，
> OOS −0.767%/t −3.23，60 日 −1.287%/t −4.85）。本文件测**组合层**：
> 把"减持公告后 20 个交易日内"的股票从 pool30 买入中剔除，是否改善策略。
> **本文件在任何 A/B 回测出数前写定；判据不再改。** 账本 N=60。
> 事件层 PASS ≠ 组合层增益；本测试可能 FAIL，FAIL 也是合法结论。

## 0. 定位与边界

- 策略叠加层测试；不改变任何生产配置，不碰信号链/执行链。
- 事件定义/20 日窗口/阈值沿用 N=59 预注册，**不调参、不网格**。
- 若通过：仅成为"候选"，部署另需信号链实现 + 资金口径三件套 + 用户拍板。
- 若失败：关闭该 overlay 方向，事件层负漂移只作为研究记录。

## 1. 事件集（冻结，沿用 N=59）

- 数据：`data_store/meta/shareholder_changes.parquet`（as_of=2026-10-20）。
- 事件：`减持`；股东名称含公司/集团/控股/投资/合伙类（排除基金/资管/信托/
  证券/保险/银行/计划）；占总股本比例 ≥0.10%；同股票 20 交易日去重取首条；
  公告日 ≤2026-09-30。
- 组合层排除窗口：调仓日 R 的交易日索引 i_R，事件日 T 的索引 i_T，
  **1 ≤ i_R − i_T ≤ 20** → 该股票在 R 日不新买（已持仓不强制卖）。

## 3. 判据（出数前锁，机械）

先跑重叠审计（`logs/shareholder_decrease_overlap_20261020.csv`，只算重叠不算收益）：

0. **可测性门槛**：被过滤的买入槽 ≥ **100**（全期）且受影响调仓日 ≥ **30**；
   否则 **不跑 A/B，结论=重叠不足，overlay 关闭**。

A/B 主判据（50万/组）：

1. `年化(过滤) − 年化(基线) ≥ +0.50pp`；
2. `夏普(过滤) ≥ 夏普(基线)`；
3. `最大回撤(过滤) ≥ 最大回撤(基线) − 0.5pp`；
4. OOS 2015-2018：`年化(过滤) ≥ 年化(基线)`；
5. **配对 block bootstrap**：月频 NAV 差，block=6、B=2000；年化差 |Δ| ≥ **1×SE**；
6. **对照画像**：无约束臂 `年化(过滤) − 年化(基线) ≥ −0.5pp`。

判定：

- 1-6 全过 → "减持回避 overlay 候选"；不部署，进入信号链实现评估（另立项）。
- 任一条不过 → **关闭该 overlay**；不调窗口/阈值/替换规则去救。
- 若 0 不过 → 不跑 A/B；记录"重叠不足"并关闭。

## 4. MDE / 功效

- 事件层效应 −0.514%/20 日、t_day −2.90；组合层可观测的是"被过滤槽位的收益差
  × 权重"。重叠槽位数由审计给出；若 ~200-500/5,510 槽（4-9%），按单槽位差

  也可能在噪声内；以 bootstrap 为准。
