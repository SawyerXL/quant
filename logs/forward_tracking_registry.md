# 前瞻跟踪注册（2026-09-13 深夜开档；2026-09-13 深夜修订用途，机器时间）

**用途（修订版，以本节为准）**：前瞻跟踪是**证伪与故障检测**机制——
实现偏差、参数漂移、regime 失效、live-vs-backtest gap。**不是小效应的
确认机制**：T=1 年 TE=3% → SE(ΔSharpe)=0.20（现有历史 0.072 的 3 倍），
确认 0.25 级 ΔSharpe 需要约 8 年。唯一例外 = **成本对账**（算术精确，
一个季度即可裁决），设为注册表第一项。

**规则**：
- 注册时点 = commit 时间戳（机器时间，不手写；commit 缺则标"未提交"
  并注明——该状态下的注册视为未生效）
- 每条必须含：可复现的量化判据定义 + 预期值 + 开始跟踪日期
- 跟踪输出：每月末更新实际 vs 预期，异常偏差记入归因
- **注册位条件（2026-09-13 深夜修正）**：免注册的唯一条件 = "持仓序列
  不变、只有成本参数变"（成本档位重算类）。任何改变持仓的改动
  （缓冲带、调仓频率、参数改动、新信号）一律占注册位；**通过候选资格
  但未注册前瞻者，下轮复审资格失效**。
