## 1. 假设（主检验，只此一条）

**H-W1**：在 2019-02~2026-10 的 CSI800 PIT 宇宙中，满足 WASHOUT_WATCH 形态的
事件，其 **T+1 开盘 → T+60 收盘**的 CSI800 超额收益 **> 0**，且在控制
"前期涨幅 + 流通市值 + 同日"后仍显著。

方向：正（洗盘完成后抛压下降）。不是"庄家持仓"假说——庄家不可观测，本检验
只检验**形态**。

## 2. 冻结参数（与 `scripts/chip_structure.py:P` 同源，改任一 = 新预注册）

| 参数 | 值 | 含义 |
|---|---|---|
| high_window | 250 | 找前期高点/涨幅窗口（交易日） |
| prior_leg_min | 0.30 | 前期拉升（低→高）≥30% |
| days_min / days_max | 10 / 60 | 距高点 10~60 交易日（≤3 个月） |
| dd_min / dd_max | −0.30 / −0.08 | 回调 −8%~−30% |
| range_width_max | 0.25 | 横盘区间宽度 ≤25% |
| turnover_min | 0.30 | 洗盘期累积流通换手 ≥30% |
| chip_window / half_life | 120 / 60 | 筹码分布回看/半衰期 |
| vol_shrink | 10d/40d | 缩量参考（仅描述，不参与状态机） |

状态机顺序：PRIOR_LEG_MISSING → JUST_HIGH → BROKEN → OVER_3M → RANGE_TOO_WIDE
→ FLOAT_UNAVAILABLE → TURNOVER_LOW → **WASHOUT_WATCH**。

## 3. 宇宙与样本

- **宇宙**：CSI800 PIT 季度成分（用 t 时点最近一期快照），2019-02-01~2026-10-23。
  指数编制本身剔除 ST，故不再用当前 ST 快照（避免前视/幸存者二次污染）。
- **上市/数据要求**：t 前本地日线 ≥250 根；t 前 20 日日均成交额 ≥5000 万元。
- **剔除**：T+1 开盘涨停（主板 open ≥ 前收×1.095；创业板/科创板 ≥×1.195），
  买不进的事件剔除并计数；停牌/无 T+1 数据剔除并计数。
- **事件**：状态机 == WASHOUT_WATCH；同一标的 60 个交易日内只取首个事件
  （去重叠）。
- **对照**：同日 × 前期 60 日收益十分位 × 流通市值五分位（固定效应），
  即只比较"同一天、涨幅相近、市值相近"的股票。**不**控制换手/波动/筹码——
  它们属于处理本身，控制会吸收效应。

## 4. 结果变量与执行口径

- 入场：T 收盘出信号 → **T+1 开盘**买入（可执行，不使用 T 收盘价）。
- 出场：T+60 收盘（主）；T+20 收盘（次）。
- 超额：个股区间收益 − CSI800 同窗区间收益（价格口径；60 日分红影响 <0.5%，
  在盲区声明中列出）。
- 成本：单边 0.10%（佣金 0.025% + 滑点 0.075%），卖出再加印花 0.05%，
  往返 **0.25%**，从超额中扣除。
- 涨跌停/停牌：入场日开盘涨停剔除；持有期内停牌按复牌首日收盘计价并计数。

## 5. 推断与 MDE（先行，出数前锁）

- 事件在时间上重叠、同月高度相关 → **主推断用月度块 bootstrap**
  （按月重采样事件月，重算均值，B=2000），报告 bootstrap t 与 95% 区间；
  同时报事件级 naive t（仅参考，不作判据）。
- **MDE 两步锁**（预注册允许"仅数事件、不看收益"的 census）：
  1. 先跑 census（只输出事件数、事件月数、参数分布、覆盖率；**不 join 前向收益**）；
  2. MDE = 2.802 × σ_resid × sqrt(2/N_eff)，σ_resid 取 **30%/年化波动先验**
     （不取自本样本结果），N_eff = 事件月数（保守，按簇计）；
     若事件级 N 也报一份 MDE_events 作对照。
  3. 把 census 的 N、N_eff、MDE 写入 `logs/prereg_washout_census_20261025.md`
     **之后**才允许跑收益。
- 判定用 **MDE_cluster（保守值）**，不是 event-level MDE。

## 7. 预先声明的子组（只描述，不作判定）

用户叙事的三条"底线"逐条对应，但**不参与 PASS 判定**，避免多重检验后择优：

3. **3 个月分水岭**：days_since_high ≤60 vs >60（>60 的事件状态机不是

4. **筹码温度**：`winner_rate` 高/低、`width90` 宽/窄分组（描述）。

## 8. 盲区（必须随结果一起报）

1. **幸存者偏差**：本地库退市股缺失；CSI800 PIT 缓解但不消除。
2. **PIT 是季度快照**，非日频成员；两次快照之间的调入/调出不可见。
3. **筹码是日线近似**：无 L2、无大宗/协议转让、无融资盘成本、无解禁；
   `cyq-perf` 只能前向核对，不能回测。
4. **庄家不可观测**：H-W1 检验的是"形态→收益"，不是"庄家行为"；
   即使 PASS 也不能证明叙事机制。
5. **2019+ 仅 ~7.7 年、约 1.5 轮牛熊**；重叠事件使有效样本远小于事件数。
6. **ST/退市/借壳**：指数编制剔除 ST，但历史 ST 状态不可得。
7. **执行**：T+1 开盘价、0.25% 往返成本、涨停剔除；真实冲击成本可能更高。
8. **分红**：价格口径，60 日分红拖累 <0.5%。
