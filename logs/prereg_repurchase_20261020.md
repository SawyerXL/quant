## 1. 机制（先于数据）

公司回购=**公司层面对自身价值的买入承诺**（董事会/股东大会批准、真金白银执行），
是比股东增持更强的信号（公司最了解自身现金流）；A 股回购制度（回购规则/库存股）
是制度根源；散户对回购计划/完成关注不足 → 公告后 20 日正漂移。方向=正（长仓）。

## 2. 数据（已审计）

- `data_store/meta/repurchase_events.parquet`（as_of=2026-10-20，5,583 条；
  实施进度：完成实施 4,992 / 实施中 353 / 停止 124 / 董事会预案 50 等）。
- 字段：代码/计划回购金额区间/占公告前一日总股本比例/回购起始时间/**实施进度**/
  已回购金额/**最新公告日期**。
- 单位：计划金额=元（中位 6,248 万，max 150 亿）；比例=%（中位 0.56%，max 46.2）。
- **PIT 处置**：
  - 主臂 A=**回购起始时间**（计划已公告、起始日公开；计划金额/比例已知）。
    起始日晚于计划公告日 → T+1 开盘入场**错过公告当日跳变**（保守，非前视）。
  - 次臂 B=**完成实施**（`实施进度=完成实施`，事件日=`最新公告日期`，即完成公告
    日；已回购金额为实际值，公告日公开）。**不用"实施中"的最新进展当事件日**
    （最新进展日=最新一次公告，历史时点未知，避免前视）。
  - 金额/比例单位与量级已审计；极端小值（1 元）按阈值剔除。

## 3. 事件定义（冻结）

- **主臂 A（计划开始）**：`回购起始时间` ∈ 2019-01-01~2026-09-30；
  **材料级：计划回购金额下限 ≥ 5,000 万元 且/或 占总股本比例上限 ≥ 1%**
  ——主定义取**金额下限 ≥5,000 万**（经济含义=公司真金白银的承诺规模）；
  比例≥1% 作诊断分层，不并入选样。
- **次臂 B（完成）**：`实施进度=完成实施`；`最新公告日期` ∈ 2019-01-01~2026-09-30；
  实际已回购金额 ≥5,000 万（材料级）。
- 去重：同一股票 20 个交易日内多次回购事件，只保留**第一条**。
- 剔除：ST/上市<60/缺 bar/E 开盘涨停/X 收盘跌停/窗口 |日跳|>50%（计数）。

## 4. 执行与收益（冻结）

- 事件日 A（起始日/完成公告日）；E=A 之后首个交易日开盘（非交易日顺延）；
  X=E+19 交易日收盘（20 个交易日含入场日）；60 日仅诊断。
- 事件收益=`close(X)/open(E)-1`；基准=同窗等权买入持有；超额=收益−基准−成本。
- 成本：主口径 **0.33% 双边**；敏感性 0.23%/0.53%。
- 统计：按入场日聚类 t；均值/中位/胜率；t_stock 诊断。

## 5. 判据（出数前锁，方向=正）

- **主臂 A 通过需全部满足**：
  1. 净超额均值 **>0** 且日聚类 **t ≥ 2.5**；
  2. OOS 2023-2026 同号且日聚类 **t ≥ 1.5**；
  3. N ≥ **500** 事件、≥ **200** 个入场日；
  4. 均值 ≥ **MDE**（2.8×日聚类 SE，按实测重算）且 ≥ 0.33% 成本。
- **次臂 B**：同样 1-4（N≥500），但**B 不得用来挽救 A**；A 不过、B 过只记录
  "完成事件候选"。
- 判定：A 全过 → "回购正漂移候选"，进入组合/容量/前向验证；任一条不过 → 关闭；
  不调阈值/窗户/去重规则。
- 诊断（不入判据）：60 日、比例分层、A vs B 差异、分年、市值/流动性分层。

## 6. MDE 先行（未看事件收益）

- 参考同类事件：20 日事件超额 SD 约 12~18%；A 预计 N 2,000~3,000、入场日
  600~900；日聚类均值 SE ≈ 0.4~0.7%；**MDE(2.8×) ≈ 1.1~2.0%**。
  正式出数用本样本日聚类 SD 重算；若 MDE >3% 则结论=不可判读。
- 经济门槛：成本 0.33% 双边；净超额须 ≥MDE。
