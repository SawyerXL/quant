## 2. H1：大比例解禁后的反转（long-only）

### 机制（先于数据）
限售解禁是**公开日历上的制度性供给冲击**（③约束驱动）：限售股东在解禁后获得
卖出权，事前抛压预期压制股价；若实际减持低于恐慌预期，解禁后出现反转。
事件日期事先可知，不存在"用结果反推事件"的前视。

### 事件定义（单一定义，不网格）
- 每个 (`股票`, `解禁时间 D`) 为一个候选事件；
- **主事件集：`占解禁前流通市值比例 ≥ 5%`**（5% 流通市值的潜在供给在经济上
  显著；单一阈值，不试 2%/10%/20%）；
- 去重：同一股票 30 个自然日内多条解禁记录，只保留比例最大的一条；
- 剔除（全部计数）：ST（用当前 ST 状态近似，历史 ST 变化为已知盲区）、
  上市 <60 日、入场/出场 bar 缺失、窗口内 |日跳|>50%、入场日开盘涨停
  （无法买入）、出场日收盘跌停（无法卖出）、非正价。

### 时点（先锁）
- `D` = 数据字段 `解禁时间`；数据表 `解禁前一交易日收盘价` 与 D 当日收盘相等，
  判定 **D 为解禁生效日、首个可卖日为 D 之后的首个交易日 E**（假设，盲区见 §6）。
- 入场：**E+1 开盘**（首个可卖日之后再等一天，避开首日抛压；最保守可执行时点）。
- 出场：**E+10 收盘**（10 个交易日）。
- 事件收益 = `close(E+10)/open(E+1) - 1`。
- 基准：**同窗等权买入持有** `mean_i(close_i(E+10)/open_i(E+1) - 1)`，
  宇宙=当日通过基本过滤的全部日线股票（与 R1 同一过滤）；
- 超额 = 事件收益 − 同窗基准 − 成本。
- 成本：主口径 **0.33% 双边**（佣金 0.13% + 滑点 0.2%）；敏感性 0.13% / 0.53%。

### 统计与判据（出数前锁）
- 事件级均值；**按入场日聚类 t**（同日多事件相关）；同时报日聚类/事件级朴素 t。
- 样本：2019-01-01 ~ 2026-09-30；IS 2019-2022 / OOS 2023-2026（OOS 只用一次）。
- **H1 通过需全部满足**：
  1. 全样本净超额均值 **>0** 且日聚类 **t ≥ 2.5**；
  2. OOS 同号且日聚类 **t ≥ 1.5**；
  3. N ≥ 200 事件、≥ 100 个入场日；
  4. 均值 ≥ MDE（按 §5 的 10 日窗口估计）且 ≥ 0.33% 成本。
- 结论方向：
  - 过 → "解禁反转候选"，进入组合/容量/前向验证，不直接入配置；
  - 不过但显著为负 → 记录"供给压力主导、无反转"，不交易；
  - 不显著 → 关闭该方向（除非新机制）。

### 诊断（不入判据）
- 5 日/20 日窗口、按解禁比例分层（≤5%/5-20%/>20%）、按限售股类型分组的
  描述性统计——**只看不判**，不得据此改主窗口/阈值。

## 3. H2：大折价大宗交易后的负漂移（回避规则）

### 机制（先于数据）
大宗交易折价是**机构卖出方为即时流动性/信息优势支付的补偿**（②结构性资金流 +
③约束驱动）：大折价 + 大成交额 = 卖方急于出清/知情卖出，二级市场随后面临
延续性抛压。A 股大宗交易制度（盘后协议、最低门槛、减持规则）是制度根源。
方向预测：**负漂移**（不是反转）。

### 事件定义（单一定义，不网格）
- 每个 (`股票`, `交易日期 T`) 的一条日汇总记录为一个候选事件；
- **主事件集：`折溢率 ≤ -10%` 且 `成交总额/流通市值 ≥ 0.5%`**
  （深折价 + 相对流通盘有材料级成交；两个经济阈值，不试其它组合）；
- 去重：同一股票 5 个交易日内多条，只保留第一条（避免重叠窗口）；
- 剔除：ST、上市 <60 日、停牌/缺 bar、入场日开盘涨停（无法买入）、
  出场日收盘跌停（无法卖出）、非正价、窗口内 |日跳|>50%。

### 时点（先锁）
- 大宗数据盘后发布 → 入场最早 T+1 开盘（闸门十九）。
- 入场：**T+1 开盘**；出场：**T+5 收盘**（5 个交易日）。
- 事件收益 = `close(T+5)/open(T+1) - 1`；基准/成本同 H1。

### 统计与判据（出数前锁）
- 事件级均值；按入场日聚类 t；IS/OOS 同上。
- **H2 通过需全部满足**（方向=负）：
  1. 全样本净超额均值 **<0** 且日聚类 **t ≤ -2.5**；
  2. OOS 同号（<0）且日聚类 **t ≤ -1.5**；
  3. N ≥ 500 事件、≥ 200 个入场日；
  4. |均值| ≥ MDE（§5）且 ≥ 0.33% 成本。
- 结论方向：
  - 过 → "大折价大宗=负漂移"候选；落地形式=**买入回避规则**（事件后 5 个
    交易日内不买入/不持有），组合层叠加需另行预注册；
  - 显著为正 → 记录"折价后反转"，**不得**直接翻转为买入信号（需新预注册）；
  - 不显著 → 关闭该方向。

### 诊断（不入判据）
- 按折价分档 / 成交额占比分档的分组描述、10/20 日窗口——只看不判。

## 6. 数据闸门与盲区

- 闸门声明（2026-10-19）：量纲/连续性/身份/覆盖率已审计（见审计文件）；
  事件日期在正式运行前再过一次交易日历（闸门二十五）。
- 已知盲区：
  1. **D→E 假设**：`解禁前一交易日收盘价` 与 D 当日收盘相等 → 判定首个可卖日
     为 D 后首个交易日；若实际可卖日就是 D，入场更晚（保守），不会制造假阳，
     但可能低估效应。
  2. 当前 ST 状态近似历史 ST（无历史 ST 面板）。
  3. 解禁股东的实际卖出行为不可观测；限售股类型/成本未知。
  4. 大宗日汇总是聚合值（多笔不同价可能被平均）；关联方对倒/过桥无法识别。
  5. 本地日线有已知幸存者偏差（大盘/中盘影响小，小盘影响大）。
  6. 事件集从全量数据构造，不条件化于结果；但样本末端（2026-09-30）之后的
     事件不完整（数据边界，闸门二十二）。
- 所有剔除/顺延/跳过必须计数并写入结果 JSON（闸门十二）。
