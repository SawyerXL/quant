## R1 埋伏次日涨停（limit-up ambush）

**目标**：T 日收盘后/次日开盘前识别"次日大概率涨停"的标的，**在涨停前**
买入，获取次日溢价；不是追涨停。

**机制假说（运行前必须补全且通过 09-07 新假设门槛）**
- 候选①制度根源：涨停板制度 + T+1 → 次日买盘集中/封板资金博弈。
- 候选②结构性资金流：龙虎榜席位/游资接力/首板溢价。
- **不合格情形**：若只能做"历史涨停名单排序"→ 排序轴变体，按门槛不合格。

**先写死的陷阱**
1. **红线**：标的已涨停时禁止买入（CLAUDE.md 风控）。埋伏必须在涨停前成交
   （T 收盘或 T+1 开盘未封板时）；一字板=不可成交样本，不得计收益。
2. **T+1**：隔夜持仓不可当日了结；回测退出规则须固定（次日开盘/尾盘）。
3. **前视**：特征只用 T 日收盘前可得信息；"当日涨停"是结果不是特征
   （若作特征必须 shift(1)，闸门二）。
4. **样本脆弱**：首板/连板样本小、事件集中；必须报样本量与分段（2019-2022/
   2023-2026），小样本结论标"待复核"。
5. **成本**：次日跳空+滑点真实计入；挂单成交不追价。
6. **MDE 先行**：先估事件频次与可观测效应，MDE > 3~5% 则不跑。

**待补（运行前）**：标的选择规则、入场时点、退出规则、样本窗、成本假设、
判据（胜率/单笔/年化 + 样本量门槛）、与现有做T/涨停纪律的冲突检查。

## R2 ZigZag 算法

**目标**：用 ZigZag 转折点（swing high/low）刻画波段结构；用途待定
（择时/进出场/仅研究可视化）。

**核心认知**：ZigZag 是**事后**极值识别，不是预测信号。

**先写死的陷阱**
1. **前视陷阱（核心）**：pivot 只有在价格反向超过阈值（百分比或 ATR 倍数）
   之后才被确认；在 pivot 日期使用 = 使用未来信息。回测必须以**确认 bar**
   （或 shift 固定滞后）为可用时点——与闸门二/前视偏差同族。
2. **阈值参数**：单一参数值禁网格（09-13 网格陷阱约束）；阈值改变即改变
   波段定义，MDE 先行。
3. **用途边界**：若仅可视化/研究 → 不进入信号链，登记即可；若升级为策略
   信号 → 必须过新假设门槛 + 多重检验预算。
4. **实现**：本仓库无现成 zigzag，需自实现 + 单测（确认滞后/单调边界/
   极值处理），并报"确认滞后分布"。
5. **与做T铁律的关系**：若用于做T进出场，必须回归 `backtest_t0_variants.py`
   同一口径复验，不得以新指标绕过既有回测纪律。

**待补（运行前）**：用途定义、阈值、确认规则、回测口径（日线/5分钟）、
判据、样本窗。

# 运行前协议草案（2026-10-19，DRAFT——待用户锁定后才可动数据）

## R1 草案：埋伏次日涨停

**机制（须先通过 09-07 门槛）**
- 制度根源：A 股涨停板 + T+1 → 涨停日的买盘排队无法当日成交，需求外溢到
  次日；信息扩散（涨停是强注意力事件）+ 连板资金的隔夜风险溢价。
- 可检验推论：**T 日（未封板）具备"次日封板倾向"特征的股票，T+1 存在
  正超额**；若超额只存在于跳空（开盘即封），则不可执行（闸门十九）。

**样本与宇宙（先锁）**
- 宇宙：沪深主板+创业板+科创板，剔除 ST（5% 档单独登记）、上市 <60 日、
  日均成交额 <1 亿；涨停幅度按板块 10%/20%。
- 事件定义：次日最高价达到涨停价 = "次日涨停"。一字板（开盘=涨停）单独
  标记为"不可执行样本"，不计收益。
- 窗口：2019-01-01 ~ 2026-09-30；OOS 只用一次（2023-2026 作为 OOS）。
- 频率：按事件计数报样本量；目标 ≥200 个可执行事件，否则标"样本不足"。

**特征（只用 T 日收盘前可得信息）**
- 连板状态（T-1 是否涨停、前 N 日涨停次数）
- 封单/炸板信息（T-1 的封单额、炸板次数——数据可得性先核）
- 成交额、换手、波动（20 日）
- 龙虎榜/游资席位（T-1 收盘后披露 → T 收盘决策可用）
- 板块热度（同板块涨停家数，T 日收盘可得）
- **禁用**：T 日是否涨停作为特征（若股票 T 日涨停 → 禁止买入，直接排除）。

**入场/出场（先锁）**
- 入场：T 收盘前（14:50-14:57）限价买入；若 T 日已涨停 → 不买（红线）。
  备选：T+1 开盘若未高开 >3% 且未一字板 → 开盘买入。
- 出场：T+1 收盘卖出（若 T+1 涨停则卖在涨停价/继续持有到 T+2 收盘，
  规则二选一，先锁）。
- 成本：双边 0.13% + 滑点 0.1%；涨停价卖出按可成交处理（卖不受限）。

**判据（出数前锁，待用户确认）**
1. **可执行超额**：T+1 收盘 vs T 收盘的等权超额（对同板块/全市场基准）
   在扣除成本后 **>0 且 t ≥ 2.5**（放开名额后的多重检验门槛）。
2. **跳空拆分**：盘中超额（T+1 开盘→收盘）必须同样为正；若超额全部在
   开盘跳空 → 判死（闸门十九）。
3. **命中率与赔率同时报**：次日涨停命中率、每次事件收益分布、最大回撤。
4. **分段**：2019-2022 / 2023-2026 分开报；两段符号相反 → 不采信。
5. **OOS 只用一次**：2023-2026 只在最终判定时动一次。

## R2 草案：ZigZag 算法

**定位（先锁）**：第一阶段=算法实现 + 描述性研究（**不进入信号链、不产生
交易信号、不耗统计预算**）；第二阶段（可选）若要用作信号，另行立项并按
新假设门槛锁判据。

**实现规格（先锁）**
- 阈值：固定百分比 X%（默认 5%，不网格）；可选 ATR 倍数版本单独登记。
- pivot 确认：价格自最近极值反向 ≥X% 时，**在确认 bar 确认 pivot**；
  回测/研究一律以确认 bar 为可用时点（禁止 pivot 日期使用）。
- 输出：pivot 序列（日期、类型、价格、确认日期、确认滞后 bars）。
- 单测：单调序列（无 pivot）、V 形、锯齿形、边界（序列末尾未确认）。

**描述性研究交付物（不出交易结论）**
1. pivot 确认滞后分布（P50/P90）
2. 波段长度/幅度分布（按板块、按年份）
3. 与已有因子（动量/波动率/成交额）的相关性
4. **明确声明**：任何"ZigZag 择时有效"的说法都需第二阶段立项，且以
   确认 bar 时点复验；本阶段不产出该结论。

**预算/统计**：第一阶段不耗统计预算；第二阶段按届时政策登记。
