## 1. 机制（先于数据）

中证800 每半年调样（6/12 月第二个星期五的下一交易日生效）。指数基金在生效日
附近被迫买入调入票/卖出调出票——**结构性资金流**，非排序轴。机制预测：
调入票在生效日收盘前获得正的强制买盘；最直接的可执行窗口=生效日前一交易日
收盘买入（公告已公开，调入名单已知）→ 生效日收盘卖出（T+1 规则允许：T-1 买入，
T 卖出）。

## 3. 执行与收益口径（先锁）

- 主臂（可执行长仓）：**调入票，T-1 收盘买 → T 收盘卖**。
- 事件收益 = `close(T)/close(T-1) - 1`。
- 基准 = **同窗等权买入持有** `mean_i(close_i(T)/close_i(T-1)-1)`（全宇宙）。
- 超额 = 事件收益 − 基准 − 成本。
- 成本：主口径 **0.33% 双边**（佣金 0.13% + 滑点 0.2%）；敏感性 0.13%/0.53%。
- 诊断（不入判据）：T-10→T-1（预期漂移）、T→T+20（生效后反转）、
  调入−调出配对差（N=42 的度量，修正日期后重算）。

## 4. 统计与判据（出数前锁）

- 事件级：**15 个半年事件**；每个事件的调入票超额均值；事件级 t =
  mean(event_means)/(std(event_means)/√15)。不用 block bootstrap（n=15 退化，
  N=42 已实锤）。
- 分段：IS 2019-2022（8 个事件）/ OOS 2023-2026（7 个事件，OOS 只用一次）。
- **主判据（全部满足）**：
  1. 全样本调入票净超额均值 **>0** 且事件级 **t ≥ 2.5**；
  2. OOS 同号且事件级 **t ≥ 1.5**；
  3. 全部事件调入数 N ≥ 500（741 ✓）；
  4. 均值 ≥ **MDE 0.73%**（保守：单事件截面 SD/√49、15 事件、含事件间离散度
     的上界估计；见 §5）且 ≥ 0.33% 成本。
- 判定：
  - 全过 → "指数调仓生效日买盘候选"，进入组合/容量/前向执行验证，不直接部署；
  - 任一条不过 → **关闭该方向**（N=42/43 的日期错位结论作废；不调窗口/阈值）；
  - 诊断若显示效应只在 T→T+20 反转而非 T-1→T，记录但**不得翻转成做空/低配
    策略**（A 股不能稳定做空；低配需另立项）。

## 5. MDE（先行，只估 dispersion，不看均值）

- 2025-06 生效日窗口单票 SD≈**2.26%**（n=101）；49 只/事件 → 事件均值 SE≈0.32%；
  15 事件、事件间独立近似 → 总体 SE≈0.08%；MDE(2.8×)≈**0.23%**。
- 保守上界：若事件均值 SD≈1%，总体 SE≈1%/√15=0.26% → MDE≈**0.73%**。
- 判据用保守上界 0.73%，避免用乐观 MDE 放过小效应。
