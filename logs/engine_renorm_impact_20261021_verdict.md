## 暴露诊断（关键）

| | 平均实际敞口 | 平均目标 | 平均缺口 | 缺口>10pp 天数 |
|---|---:|---:|---:|---:|
| 生产 | 18.43% | 56.40% | 38.33pp | 1346/1957 |
| 沙箱 | 18.59% | 56.40% | 38.17pp | 1345/1957 |

重归一**几乎不改变平均敞口**——主导因素是 **lot 跳票现金拖累**（32万/组
935 次跳票）+ 2019 暖机，而不是幸存者权重漂移。这解释了股腿只有 1.5%：
它不是"选股没收益"，而是**大部分时间只用了约 18% 的股票资金**。

## 结论

1. **现有 40/60 与 5% 卫星结论对重归一 bug 稳健**：年化差 −0.04pp、
   回撤反而改善 0.14pp、卫星余量 +0.13pp（全部在噪声内）。
   **不需要为 40/60 重跑校准。**
2. 内存中 "+7.2% 高估" 是 **100万×60 / 50万组** recon 的口径；32万/组×30
   因 lot 跳票主导，重归一效应被稀释。**若引用 live 100/60 的绝对回测数，
   仍应先用沙箱引擎重跑 50万/组**（本次未跑）。
3. 更大的结构问题不是 bug，而是 **lot 跳票导致的 18% 平均敞口**；这与
   "股票腿是拖累"的结论同源，配比/组资金调整应优先看它。
4. 生产引擎保持不动；本次不改任何配置。

## 盲区

- 沙箱的涨停/跌停处理沿用生产语义的简化版（跌停旧仓保留原权重、涨停新票
  剔除不重归一），极端涨跌停日可能与实盘有细微差异。
- 暴露均值未剔除 2019 暖机（前 250 日目标 1.0、实际 0），缺口含暖机贡献；
  即便只看投资期，"lot 跳票留下现金"的方向不变。
- 单引擎、单窗口；结论用于"是否需要重跑"，不是新策略结论。

## 补充：live 100/60（50万/组 × 62.5/37.5，月度 CB）

| | 生产（buggy） | 沙箱（重归一） | 差 |
|---|---:|---:|---:|
| 股腿 50万/组 | 2.57% / 0.293 / −21.72% | 2.41% / 0.284 / −20.07% | −0.16pp |
| **live 100/60** | **9.14% / 1.051 / −10.14%** | **9.03% / 1.059 / −10.32%** | **−0.11pp** |
| +5% 卫星 | 9.66% / −10.08% / 余量 4.92 | 9.55% / −10.00% / 余量 5.00 | −0.11pp / +0.08 |

分年：2025 生产 +9.43% vs 沙箱 +5.00%（−4.43pp），2026 −8.91% vs −6.93%
（+1.98pp），全期净差 −0.11pp——仍是正负相抵，不是单向高估。

**结论：live 100/60 对重归一 bug 同样稳健（Δ −0.11pp，噪声内）。**
旧记忆 "+7.2% 高估" **未在 50万/组×30/lot=100/月度 CB 上复现**；该数应
来自另一种 recon（100万×60 或无 lot/日频补买的 sim），**不得再当作当前
live 配置的偏移量引用**。

暴露诊断（50万/组）：平均实际敞口 **22.13%** vs 目标 56.40%——lot 跳票
现金拖累依旧；live 100/60 的 9.14% 可拆为 `0.625×2.57 + 0.375×20.08`，
**收益主要由 CB 腿承担**，股票腿大部分时间是现金。

**处置：当前 40/60 与 live 100/60 都不需要因该 bug 重跑校准；引擎修复
维持延期（语义正确性债，等配置变化使其变大时再做）。**
