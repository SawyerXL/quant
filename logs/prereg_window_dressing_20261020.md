# 季末窗口粉饰（window dressing）— 约束驱动候选（预注册，2026-10-20 出数前锁）

> 机制类：**约束驱动（公募季末排名/持仓披露）**，属项目新假设门槛的合格三类之一。
> 账本 **N=66**；OOS 仅一次；窗口/阈值不网格。核心 40/60 与 15% 线不动。

## 1. 机制（先于数据）

公募基金季末需披露持仓与排名；在季末前 5 个交易日买入当季赢家、卖出输家可
美化组合表现（window dressing），形成暂时性价格压力；季末后压力消失，出现
反向修正。A 股公募季度考核与披露制度提供制度根源。

## 2. 数据与单位

- 本地日线 qfq，非 ST、上市 ≥250 日、价格有效；2019Q1~2026Q3（31 个季末）。
- 已知数据口径：库内 qfq 混存（部分旧史不复权）——本检验只用**季度内相对收益**
  与 5 日短窗，跨除权跳变按 |日跳|>50% 剔除；结论须附此盲区。

## 3. 事件定义（冻结）

- 季末窗口 = 每个季度**最后 5 个交易日**（[QE−4, QE]）。
- 信号日 = QE−5 交易日收盘；QTD 收益 = close(信号日)/close(上季末) − 1。
- 截面十分位：赢家 D10（前 10%），输家 D1（后 10%）；基准 = 全样本等权。
- 入场 = 窗口首日开盘（信号日次日）；出场 = QE 收盘。
- 剔除（计数）：入场日开盘涨停、出场日收盘跌停、窗口内 |日跳|>50%、缺 bar。
- 修正窗：下一季度**前 5 个交易日**，同一分组，入场首日开盘、出场第 5 日收盘。

## 4. 收益与统计（冻结）

- 事件收益 = 出场收盘/入场开盘 − 1；成本 **0.33% 双边/腿**（多空差 0.66%）。
- 主统计：**按季度聚类的 t**（31 个独立季末，保守）；日聚类 t 仅诊断。
- MDE = 2.8 ×（季度间 SD / √季度数），先行披露。
- IS 2019-2022（16 季）/ OOS 2023-2026（15 季）。

## 5. 判据（全部满足才 PASS）

主检验 = **窗口内 赢家 − 输家** 多空差：

1. 均值 >0 且季度聚类 **t ≥ 2.5**；
2. OOS 同号且季度聚类 **t ≥ 1.5**；
3. 平均每季每臂 ≥200 只、有效季末 ≥20 个；
4. 均值 ≥ MDE 且 ≥0.66% 成本。

诊断（不入判据）：赢家 − 基准；修正窗（D10−D1）是否 <0；分年/分市值。

任一条不过 → 关闭；不调窗口（5 日）/阈值（十分位）/聚类口径。

## 6. 盲区

1. 独立季末仅 31 个，有效样本小；季度聚类 t 已按此保守处理。
2. QTD 排序本身是季度动量轴——窗口效应可能与动量/反转混杂；只测季末时点增量。
3. 公募披露/考核制度 2019-2026 可能变化；单一市场。
4. 数据复权口径混存；除权跳变剔除后仍可能有小误差。
5. 即使 PASS，事件级效应需再过组合层 overlay（N=52/60 教训：事件层 PASS ≠ 组合层增益）。
