# 大宗回避过滤 × pool30 — 组合层 overlay 预注册（2026-10-20 09:0x，出数前锁）

> 来源：#21 H2 事件层 PASS（`logs/overnight_open_questions.md` 六十五轮：
> 深折价大宗事件后 5 日净超额 −0.4954%/t=−6.91，OOS −0.4633%/t=−4.27，
> N=18,851）。本文件测**组合层**：把事件后 5 日的股票从 pool30 买入中剔除，
> 是否改善策略。**本文件在任何 A/B 回测出数前写定；判据不再改。**
> 注意：事件层 PASS ≠ 组合层增益；本测试可能 FAIL，FAIL 也是合法结论。

## 0. 定位与边界

- 这是**策略叠加层测试**，不是新事件方向；不改变任何生产配置，不碰信号链/执行链。
- 事件定义/5 日窗口/阈值完全沿用 #21 预注册，**不调参、不网格**。
- 若通过：仅成为"候选"，部署另需信号链实现 + 资金口径三件套 + 用户拍板。
- 若失败：关闭该 overlay 方向，事件层负漂移只作为研究记录。

## 1. 事件集（冻结）

- 数据：`data_store/meta/block_trade_events_2019_2026.parquet`（as_of=2026-10-19，
  120,130 行；抓取/单位/身份审计见 `logs/data_audit_index_unlock_block_20261019.md`）。
- 过滤：`折溢率 ≤ -10%` **且** `成交总额/流通市值 ≥ 0.5%`。
- 去重：同一股票 5 个交易日内只保留第一条（与事件研究一致）。
- 样本：2019-01-01 ~ 2026-09-30（事件日期；回测窗口到 2026-10-19）。

## 2. Overlay 实现（冻结）

- 在**研究引擎** `scripts/backtest_engine.py` 的 `apply_filters` 内加入可选
  `exclude` 集合：被排除的股票不进入 eligible 列表，**由下一名合格候选补位**
  （替换，不是留现金）；默认 `exclude=None` 时行为与现状逐位一致。
- **仅排除非持仓候选（不新买）**：已持仓股票即便命中事件也不强制卖出
  （`held` 豁免），避免把"回避新买"测试变成"事件强制卖出"测试；后者更强，
  另立假设。
- 重叠审计（2026-10-20 09:3x，只算重叠不算收益，`logs/block_filter_overlap_20261020.csv`）：
  **113/5,510 买入槽（2.05%）、78/186 调仓日受影响**——满足门槛 0（≥100 槽、
  ≥30 日），允许进入 A/B。被排除名单含东财/宁德/中信/中芯等大票，不是纯小盘。
  审计修正两处口径 bug：面板索引错位（用 2014 起日历切 2019 起面板）、
  `max_vol20=5.0` 是日波动×100 而非年化——修正后才有上述数字。
- 排除映射：调仓日 R 的交易日索引 i_R，若股票 c 有事件日 T 的索引 i_T 满足
  **1 ≤ i_R − i_T ≤ 5**，则 c 在 R 日被排除（事件盘后发布，R 日买入可用；
  不假设 T 日当天可用）。
- 引擎/配置：`DEFAULT_CONFIG`（pool30 / shift −0.03 / 现金 1.4% / limit_gate /
  max_vol20 5% / lot_size=100 / initial_capital=500,000）；日程=实盘语义
  `rebalance_schedule`；as_of=2026-10-19。
- 窗口：全期 2019-01-01~2026-10-19；OOS 2015-2018（薄数据）。
- 对照臂：无过滤基线（同引擎、同数据、同日程；先验证与 #18 基线逐位一致）。
- 资金画像：主判据=**50万/组**（lot 约束）；对照=**无约束**（profile 稳健性）。

## 3. 判据（出数前锁，机械）

先跑**重叠审计**（`logs/block_filter_overlap_20261020.csv`，只算重叠不算收益）：

0. **可测性门槛**：被过滤的买入槽位 ≥ **100**（全期）且受影响调仓日 ≥ **30**；
   否则样本不足 → **不跑 A/B，结论=重叠不足，overlay 关闭**。

A/B 主判据（50万/组）：

1. `年化(过滤) − 年化(基线) ≥ +0.50pp`；
2. `夏普(过滤) ≥ 夏普(基线)`；
3. `最大回撤(过滤) ≥ 最大回撤(基线) − 0.5pp`（不显著变差）；
4. OOS 2015-2018：`年化(过滤) ≥ 年化(基线)`（同号/不伤）；
5. **配对 bootstrap**：月频 NAV 差（过滤−基线），block=6 个月、B=2000；
   年化差的 |Δ| ≥ **1×SE**（否则=测不出，不判定通过）；
6. **对照画像**：无约束臂 `年化(过滤) − 年化(基线) ≥ -0.5pp`（不能只在 lot
   画像有效；profile-dependent 视为非稳健，不采纳）。

判定：

- 1-6 全过 → "大宗回避 overlay 候选"；不部署，进入信号链实现评估（另立项）。
- 任一条不过 → **关闭该 overlay**；不调 5 日窗口/阈值/替换规则去救。
- 若 0 不过 → 不跑 A/B；记录"重叠不足"并关闭。

## 4. MDE / 功效

- 事件层每事件 −0.495%、t=−6.91；组合层可观测的是"被过滤槽位的收益差 × 权重"。
  重叠槽位 n、单槽位等效权重 1/30、5 日事件差 ~−0.5%~−1.2%（事件层中位 −1.24%），
  组合层年化差的粗略量级 ≈ (n/总槽位) × 年换手放大 × 单槽位差。
- 若重叠 ~100/5640 槽位（1.8%），按每次过滤槽位差 −1.2%、年换手 150% 粗估，
  年化差量级 ~0.3~0.6pp——**可能在判据 +0.5pp 边缘**；因此 B 门槛（≥100 槽）
  与配对 bootstrap 必须同时看，不以点估计单独裁定。
- 事件重叠的准确数字由审计给出；本文件先锁门槛，不先看收益。

## 5. 多重检验与盲区

- 本 overlay 是 #21 家族的第 3 个检验（H1 解禁、H2 大宗事件、本 overlay）；
  账本序号顺延 N=52；引用须写累计检验数。
- 盲区：
  1. 事件集的负漂移可能含**小盘/低流动性风格**；overlay 的 A/B 是组合层直接
     对照，但仍需在报告中给出被过滤股票的市值/流动性画像（描述性），不得把
     风格当 alpha。
  2. block 日汇总是聚合值；关联方对倒不可识别。
  3. 研究引擎的 floor-to-lot/不重归一行为与生产一致（已知挂账）；只做同引擎
     横向比较。
  4. 生产信号链若没有"下一名补位"机制，部署需另行实现与验证——本测试的
     "替换"语义不等于生产可直接落地。
