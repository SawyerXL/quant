# 下修标记分桶判读模板（预登记，2026-10-01 锁定）

> 锁定声明：本模板在**未见过全量数据**的状态下定稿（数据接触仅=20 券采样，
> 用途限于框架 PIT 逻辑测试，未用于任何判据要素的设定）。全量摄取（308 券
> MCP G2）在模板锁定后执行；模板要素不得在见到全量分布后修改——判据先于数据。

## 0. 定位声明（写死）

- 本检验 = **风险标记候选**，不是 alpha 因子；显著 ≠ 入 dblow
- **非 v2 后门**：标记有用 ≠ 重开 premium（price-only 是定案）
- 检验序号待入检验账本（占多重检验预算的登记行）

## 1. 分桶与对比

- 分桶 = PIT 下修次数 {0, 1, 2+}（单次事件降幅 >5% 计下修；PIT 按 change_date，
  未来事件不可见——陷阱防护已测）
- **对比一（主检验）**：{1,2+} vs {0}——有下修史 vs 无
- **对比二（剂量响应）**：{2+} vs {1}——多次 vs 单次

## 2. 收益窗口

- **持有月收益**（调仓日选入后 1 个持有周期的收益）——横截面版，与 09-29 立项
  口径一致（"下修史横截面标记分桶月收益"）
- 事件版（下修事件后 1/3/6 月事件相对收益）**不并入本检验**，如需要另立项

## 3. 统计判据

- 双侧 t（不预设符号——力保转股=正面 vs 基本面恶化=负面，两个方向都是合法结果）
- α=0.05 总量；两对比 Bonferroni → 每对比 α=0.025
- 券-月观测**按券聚类**（同券多月观测相关，naive t 会虚高）；报告同时给 naive t
  与聚类 t，判定以聚类 t 为准
- 期望假阳声明：两对比在 0.05 总量下期望假阳 = 0.05×2 家族级（按检验账本惯例附）

## 4. 样本下限（N 的准确定义）

- **N = 券-月观测**：每桶 ≥ 50
- 每桶**独立券数 ≥ 10**（聚类有效性前提）
- 事件数不设下限，但记录（若事件级分析将来需要，另立项）

## 5. 结论与处置（三种全部合法，无"必须有效"）

| 结论 | 条件 | 处置 |
|---|---|---|
| A. 显著 | 任一对比聚类 t 显著 | 记入风险标记注册表；方向事后解读（正=力保转股溢价，负=基本面恶化折价）；**不自动入 dblow** |
| B. 不显著 | 两对比均不显著 | 结案记录（下修标记无预测力）；预算不退 |
| C. 剂量响应 | 对比二显著且方向与对比一同向 | 并入 A 的记录，注明剂量响应存在 |

**入 dblow 的前置（任何结论下都不变）**：独立立项 + 参数三件套（事前预测登记/
判读矩阵/归因闸门）。本检验不提供该路径。
