## 1. TE 估计方法锁死（干净库重跑时不得重选）

**问题**：σ 的估计方法本身是自由参数。仅估计频率一项（日频→月频）就把
择时 σ 从 0.93 移到 0.76（移动 0.17），而组件距门槛的余量只有 0.14。
其余旋钮还有：对数 vs 简单收益、重叠 vs 非重叠窗口、√12 vs √252 年化、
是否去均值、全期 vs EWMA——每个 ~0.05-0.15σ。五个方向 × 若干旋钮，总
能找到一组让任何方向过线的组合。这是 5.7pp 误用事件的下一代形态：不是
数字换名字，是估计量自由度在门槛附近制造结论。

**锁定**（看结果之前）：

```
TE   = 月频非重叠对数收益差分序列的样本标准差 × √12
       全期估计；不做收缩；不做自相关校正
SE   = TE / √T，T = 实际年数
判据 = σ = 效应 / SE ≥ 0.35 → 候选资格（非确认）
```

- **唯一实现**：`scripts/single_var_harness.py` 的 `te_stats()`。重跑用代码，
  不用公式——代码是锁的唯一物理形式。
- **作用域**：同时应用于当初已通过的方向（择时 σ0.76、组件 σ0.49 也须按
  此方法重算），不限于五个被杀方向的复审。
- 锁在结果之前 = 纪律；锁在结果之后 = 选择。任何"干净库重跑时重新选方法"
  的提议视为违反本锁。

## 2. σ 报告规则（与 §1 并列）

σ = 效应 / SE。此前报告的 [0.71, 0.82] 区间只反映了**分母 TE 的估计误差**，
把分子（效应）当成已知常数——但分子的误差恰恰是 SE 本身，是整个统计量
存在的理由。真实情况（旧库数示例）：效应 +4.38pp，SE 5.75pp → 效应 95%
区间 ≈ [−6.9, +15.7]pp，**连符号都不确定**。报一个漏掉主导项的窄区间，
比不给区间更有误导性。

- **σ 只报点值，不报区间。**
- 要表达不确定性就报 **效应 ± SE**（或 ±1.96SE 的 95% 区间）。
- 旧文档中的 [0.71, 0.82] / [0.46, 0.53] 区间一律撤回，改用上述格式。

## 8. 目标函数与可估性（2026-09-13 深夜用户裁定，周二复审出数前锁死）

等波动框架下年化收益与夏普是同一量的两种写法——真正的目标函数只有两个：
**① 风险调整后收益（夏普）② 回撤形状（尾部）**。二者的可估性差一个
数量级，这决定方向排序。

### 8.1 夏普只报配对差，禁止报绝对值

```
SE(Sharpe) ≈ √((1 + S²/2) / T)
S=0.8, T=7.7 年 → SE ≈ 0.41
```

**夏普 0.8 和 1.2 在 7.7 年样本上区分不开**——"把夏普从 0.8 提到 1.0"
是不可证伪的目标。配对比较完全不同（与 TE 作用域同构）：

```
SE(ΔSharpe) = TE/vol / √T      （TE=差分序列年化波动, vol=臂年化波动）
TE 3%, vol 15%, T 7.7 → SE(ΔSharpe) ≈ 0.072 → ΔS ≥ 0.25 即可显著
```

绝对 SE 0.41 vs 配对 SE 0.072，差 ~6 倍。**规则：任何夏普结论只报
"相对基准 ΔSharpe = Y ± SE"，禁止报"某方案夏普 = X"。** 与 §1 同级
锁死；harness 输出格式按此调整。

**0.072 是条件值不是常数（2026-09-13 深夜修正）**——SE(ΔSharpe) 随
TE 线性变化：

| 对比 | TE | SE(ΔSharpe) | 可分辨 ΔS |
|---|---|---|---|
| 权重/再平衡类 | 3% | 0.072 | ≥ 0.25 |
| 组件 A3−A2c | 9% | 0.22 | ≥ 0.75 |
| 池 A1c−A0 | 12.2% | 0.29 | ≥ 1.0 |
| 择时 A2c−A1c | 15.8% | 0.38 | ≥ 1.3 |

**约束（与 §1 同级）：ΔSharpe 的 SE 必须用该对比自身的 TE 现算，
禁止引用本节示例的 0.072——5.7pp 同型。harness 自行计算并打印 TE，
不允许人填。**

### 8.2 最大回撤禁止作为优化目标 → CDaR

MaxDD 是整条路径的**一个观测**——抽样误差极大、对路径顺序高度敏感，
在 7.7 年上比较两个方案的 MaxDD 等于比较两个随机数，且 0.35σ 门槛
拦不住它（没人给 MaxDD 算 σ）。

```
主指标: CDaR —— 最差 5% 回撤日的平均深度
辅助:   下行波动、最差 5 次回撤的均值
误差棒: block bootstrap × 1000 次重采样; 块长 = 63 日(季度尺度,
        或 stationary bootstrap 平均块长 63)——回撤是跨月尺度现象,
        21 日块会打散回撤持续性、系统性低估 CDaR 置信区间。
        锁理由: 块长须 ≥ 目标统计量的典型时间尺度。
敏感性: 同时报 21/63/126 三档; 结论随块长翻转 → 结论不成立。
        (块长敏感性是结论的一部分, 不是被选定后隐藏的旋钮)
```

block bootstrap 给回撤类指标一个诚实的置信区间——预期效应：很多
"MaxDD 差 5pp"会当场显出在噪声内，砍掉一批看起来诱人的方向。

### 8.3 可估性排序 = 方向选择的真正依据

| 量 | 估计精度 | 能否不回测直接算 |
|---|---|---|
| 换手与成本拖累 | 精确 | **能** |
| 波动率 | 高 | 部分 |
| 相关性 | 中 | 否 |
| 回撤分位 | 低 | 否（需 bootstrap） |
| 预期收益 | **极低** | 否 |

一周的数据质量努力不改变收益估计的误差来源——**收益误差从来不是数据
造成的，是样本量**。分母侧与成本侧的改进可确认，分子侧基本不可确认。
**方向排序：成本 → 风险控制 → 广度 → 选股。**（选股已由自身数据判负：
池 A1c−A0 = −2.10σ 显著为负；模型形状=800等权+现金基础层，努力全投
择时层与成本。）

### 8.4 成本是算术级改进（d(年化)/d(换手) 精确已知）

0.13% 与 0.30% 档的差不是统计估计：同一条交易序列下
**Δ年化 = −Σ(换手量 × 成本差)**。任何降换手的改动收益可直接算。
**免注册条件（2026-09-13 深夜修正）**：不是"属于成本侧"，而是
**"持仓序列不变、只有成本参数变"**——缓冲带（改持仓成分）、调仓
频率（改持仓时点）都改变持仓，一律占注册位；只有成本档位重算类真免。

**本周首选 = 择时层换手成本量化（取代缓冲带）**：实盘形状是
800等权+现金+择时，换手主导项是择时层二值进出（每次翻转 ≈200%
单边换手；若 MA10 年翻转 6 次 × 200% × 0.30% ≈ 3.6pp/年——与全部
待决效应 0.63/1.40/4.38pp 同量级或更大）。先纯计数（不回测）：
1. 数 MA10 信号年均翻转次数
2. × 每次实际换手率 × 成本档
3. 择时层成本拖累 = 0.13% 与 0.30% 各一个
若确为 3pp 级 → **分档执行**（0/50/100 或按 MA 距离连续）三项同向：
换手降（算术可确认）+ 二值→连续有效广度升（§8.5）+ 单次误判伤害降。
次选（各占注册位，先登记后跑）：调仓频率 / 缓冲带
（引擎已有 rank_buffer_mult）。

### 8.5 广度是唯一不需要新 alpha 的结构杠杆

TE 高达 13~16%、σ 只有 0.76 的原因。候选（消耗预算，事前登记单参数）：

## 9.1 §9 收口规则补锁（2026-09-16 19:08 登记，臂级结果未出）

登记时点声明：此时臂级 4 组数只出了 A1c_close 一组（−4.99%，10 路径）；
Δ_timing 的输入（A1c_t1open / A2c_close / A2c_t1open）尚未出。全量 A3
完整栈 Δ=−0.07pp 已见——**本规则只锁臂级判读，不锁全量判读**。

**判读对象（逐路径配对，N=10）**：
```
Δ_timing[p] = (A2c_close[p] − A1c_close[p]) − (A2c_t1open[p] − A1c_t1open[p])
```
= 择时效应的两种执行差，每路径一个值，共 10 个。

**收口规则（锁死）**：
1. 报三个数：Δ_timing 的 **中位数 / 极差 / 符号一致性**（同号路径数，
   Δ=0 计入不一致）；另报配对散布（Δ_timing 的 std）并**与未配对散布
   对比**（配对是否压噪是出数后的观察，不许假定它变小）。
2. 档位判据以**中位数**为准（|中位数| < 1.0pp 第一档 / 1.0~2.5pp
   依赖执行 / >2.5pp 非可实现 alpha），极差进旁注不进判读。
3. **符号不一致路径 > 3/10 → 不出裁定**，标"路径依赖，执行价选择
   不可收口"。中位数落在任何档位都不算数。
4. **噪声地板必须进裁定措辞**：噪声（配对散布或路径散布中较大者）
   大于 |Δ| 时，措辞 = "在路径噪声 ±Xpp 下，两种执行价的择时效应差
   不可分辨"，**禁用"已验证等价/可接受"**；操作上维持 close 执行
   （无证据说它更差）是"未发现差异"的推论，不是"已验证"的推论。
   两个词在账本里不许混用（同"未发现效应"vs"无法分辨效应"纪律）。
5. 换 VWAP/均价/分批等更有利假设 = 仍禁止（§9 原锁）。
