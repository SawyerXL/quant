## 1. TE 估计方法锁死（干净库重跑时不得重选）

**问题**：σ 的估计方法本身是自由参数。仅估计频率一项（日频→月频）就把
择时 σ 从 0.93 移到 0.76（移动 0.17），而组件距门槛的余量只有 0.14。
其余旋钮还有：对数 vs 简单收益、重叠 vs 非重叠窗口、√12 vs √252 年化、
是否去均值、全期 vs EWMA——每个 ~0.05-0.15σ。五个方向 × 若干旋钮，总
能找到一组让任何方向过线的组合。这是 5.7pp 误用事件的下一代形态：不是
数字换名字，是估计量自由度在门槛附近制造结论。

**锁定**（看结果之前）：

```
TE   = 月频非重叠对数收益差分序列的样本标准差 × √12
       全期估计；不做收缩；不做自相关校正
SE   = TE / √T，T = 实际年数
判据 = σ = 效应 / SE ≥ 0.35 → 候选资格（非确认）
```

- **唯一实现**：`scripts/single_var_harness.py` 的 `te_stats()`。重跑用代码，
  不用公式——代码是锁的唯一物理形式。
- **作用域**：同时应用于当初已通过的方向（择时 σ0.76、组件 σ0.49 也须按
  此方法重算），不限于五个被杀方向的复审。
- 锁在结果之前 = 纪律；锁在结果之后 = 选择。任何"干净库重跑时重新选方法"
  的提议视为违反本锁。

### 1.1 修正中立性检验：已部分自证（2026-09-13 晚用户裁定）

锁定方法下，三行的变化不都是放宽：

```
择时臂:  锁定 SE 5.75pp ≈ 旧统一 5.70pp → 4.38/5.75=0.76σ vs 0.77σ
         差 0.01σ——"套用他对 SE"的错误对择时臂在数值上不存在,
```

> 实质影响（组件 0.25→0.49σ），对高 TE 对比方向相反（池臂 |σ| 下降）。
> **修正不是单向放宽**——中立性检验已自证一半，剩余 = 池臂月频重算。

## 2. σ 报告规则（与 §1 并列）

σ = 效应 / SE。此前报告的 [0.71, 0.82] 区间只反映了**分母 TE 的估计误差**，
把分子（效应）当成已知常数——但分子的误差恰恰是 SE 本身，是整个统计量
存在的理由。真实情况（旧库数示例）：效应 +4.38pp，SE 5.75pp → 效应 95%
区间 ≈ [−6.9, +15.7]pp，**连符号都不确定**。报一个漏掉主导项的窄区间，
比不给区间更有误导性。

- **σ 只报点值，不报区间。**
- 要表达不确定性就报 **效应 ± SE**（或 ±1.96SE 的 95% 区间）。
- 旧文档中的 [0.71, 0.82] / [0.46, 0.53] 区间一律撤回，改用上述格式。

## 3. 网格陷阱与两条约束（写入登记模板，不可协商）

"0.35σ + 参数网格"的组合：4 方向 × 5 网格点 = 20 次检验，单边
p(0.35σ)≈0.36 → 零真实效应下期望"通过" ≈ 7.3 个。在这个设定下一定会
找到能改进模型的东西，而且几乎全是假的——比数据污染危险，污染至少会
被审计抓到，过拟合不会，它长得跟发现一模一样。

- **(a) 每个方向只登记一个参数值，不做网格。** 想不清楚该取哪个值，
  说明这个方向还不该占预算。
- **(b) 先算 MDE（最小可检出效应 = 0.35 × SE），不够就别跑。**
  MDE > 可信效应量 → 不跑。**MDE 表是事前登记的一部分，用错口径
  （日频估 TE）等于登记无效**（2026-09-13 晚用户裁定）。
- **(c) 能算的不要测。** 再平衡频率的效应几乎全是换手成本，可以直接算
  出来；测会引入噪声，算不会。能省掉一整个方向的预算。

### D4 现金档位 —— 暂不登记（2026-09-13 晚用户裁定）
- 唯一变量：tier0（熊档）仓位（现网 0.30）。参数值未定，未锁定前不占预算。
- **解析估计前置**（与 tier 驻留时间统计同时做）：
  等波动缩放下，改 tier0 仓位会被杠杆重标部分抵消（仓位→0 → 组合波动

## 7. vol20 NaN 规则锁（引擎现状 + 2026-09-13 晚两处硬化，与 §1 同级）

来源：`backtest_engine.py` inv_vol 加权段。**锁定 = 引擎现状**；引擎
改动此段 = 违反方法锁，须走参数变更流程。

```
窗口:    T-1 严格——21 根 bar 止于 i-1, pct_change → 20 个日收益
NaN:     断裂日 close→NaN 产生的 NaN 收益跳过(dropna),
         窗口向后延长直至取满 20 个有效日收益
样本不足: 有效样本 <10 → 该票无 vol 条目, inv_vol 重配取均值权重
         (vols.get(c, 1.0) = 平均权重, 等价退化为等权; 保守方向=减配, 维持)
下限:    vol 下限 0.5%→5%(年化)——2026-09-13晚用户裁定: A股个股年化
         <5% 基本不存在, 0.5% 是未经检验的常数(与 5.7pp 同型)
上限:    权重因子 ≤ 3×等权(min(1/max(v,0.05), 3.0))——断裂日 NaN 被跳过
         →有效样本减少→vol 低估→权重放大, "数据质量最差的票拿最大权重"
         必须封死(与"样本不足→减配"方向互补)
波及:    拥挤度过滤(max_vol20)与 lowvol 池同用跳过语义(未加硬化的段)
```

用户列出的四选项（跳过/前向填充/整窗作废/√(n/n_valid) 缩放）中，引擎
实现的是第一项+延长补足——**选择已由代码做出，锁即文档化，不再重开**。
两处硬化（下限 5% + 上限 3×）为 2026-09-13 晚用户裁定修订，仅影响
inv_vol 分支，无任何现网臂使用该分支（DEFAULT weight_scheme=equal）。
