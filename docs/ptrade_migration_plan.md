## 4. Phase 2 — 实盘分批替换（约6周，3批，对齐双周调仓日）

前提：决策点 1/2/4 已拍板、回测+小资金实盘验证通过（§3.4）、实盘权限+程序化报备完成。

替换时点全部对齐策略调仓日（月中 + 月末倒数第二），卖出端人工分批，买入端交给策略：

| 批次 | 时点 | 卖出（人工） | 买入（策略自动） |
|---|---|---|---|
| 批1 | 第1个调仓日 | 非池持仓的1/3（先卖流动性最好、离池子最远的：科创50ETF 先动一部分） | 当日14:40起按信号建仓，随现金到账逐步达到目标的1/3 |
| 批2 | 第2个调仓日(+2周) | 再卖1/3 | 补齐到2/3 |
| 批3 | 第3个调仓日(+4周) | 清完非策略持仓（含拍板后的万泰） | 满配 |

机制说明：
- 策略资金 = 账户净资产 − IGNORE仓市值，**随人工卖出自动增长** → 每批卖出腾出的现金
  在下一个调仓日被策略自动买入，天然实现"逐步"且买入时点严格对齐信号
- 中信/恒瑞/雅克已在池内 → 策略接管（池子双周变，被换出就按纪律卖）
- 当前仓位档 70%：目标股票市值 = 策略资金×70%，存量已超 → 整体是净卖出过程
- 每批后核对：持仓 = 策略目标 + IGNORE保留项，对不上立即查
