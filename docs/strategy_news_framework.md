# 国家战略 / 金融战略 / 外围消息研究框架（2026-10-26）

> 目的：把“国家战略、金融战略、消息面”从叙事变成可验证、可回测的事件条件。
> 纪律正文见 `CLAUDE.md` 政策/消息事件纪律第 7 条与
> `docs/daily_market_study_charter.md` §6；本文是 A 层（战略）与 B 层
> （消息/外围）的**主题地图 + 回测队列**，不是交易信号。

## 0. 三层分工

| 层 | 回答 | 输出 | 能否直接下单 |
|---|---|---|---|
| A 国家战略/金融战略 | 未来 1-4 个季度政策往哪走、利好谁 | regime/风格/仓位背景 | 否 |
| B 消息面/外围 | 今天/本周发生了什么、gap 怎么开 | 事件条件、gap 提示 | 仅过闸门后 |
| C 市场结构 | 今天收在哪、广度/波动/基准率 | 方向/波动分布 | 研究输出 |

**A 层不能替代 C 层的日内方向；B 层外围只改跳空；C 层是基准分布。**

一致，不能反推成“新质生产力政策失效”或“国家战略转向”。

## 3. 外围消息/隔夜层

### 3.1 每日必录快照

`preopen_check.py` / `overnight_market` 09:03 输出：

- 美股：标普/纳指/道指（收盘；盘中 live 必标 as_of）
- 利率/汇率：美债10Y、美元指数、USDCNH/离岸人民币
- 商品：WTI/Brent、LME 铜、黄金
- 亚太/离岸：日经、恒生、A50 期货、FXI/KWEB/ASHR
- 隔夜新闻：Fed/关税/制裁/地缘/中美/OPEC/非农/CPI

### 3.2 映射规则

1. **外围只改 gap，不改收盘方向**；历史证据：外盘信号主要落在跳空，
   盘中≈抛硬币。
2. 必须拆 `gap_ret = open/prev_close−1` 与 `intraday_ret = close/open−1`。
3. 未来事件（Fed/关税/OPEC/非农）**不预埋**；事件发生后才做 T+1 开盘
   条件评估。
4. live 盘中快照不能当收盘；09:03 的收盘快照才是正式记录。
5. 只有过闸门十九/MDE/OOS 的外围事件才可进仓位；否则只写 gap 提示。

### 3.3 可回测外部事件 schema

`event_time / source / category(US_index|Fed|tariff|sanction|oil|USDCNH|Asia) /
actual_vs_expected / scope / entry=T+1_open / horizon_d=1,5 /
gap_ret / intraday_ret / control / MDE / OOS / status`

已有结论直接复用，不重复判死：美股三指数/铜对次日 A 股有预测力但主体在
gap；恒生零预测力；金/铜“开盘操作”降级为跳空提示。

## 5. 数据缺口

- 官方文件时间戳：gov.cn/央行/证监会/财政部/发改委/工信部/商务部/统计局
  需要人工或专门抓取；`news_feed.csv`（新浪全球）只是候选源。
- CCTV 新闻联播 22:35 抓取；22:45 台账；09:03 盘前补外盘。
- 事件表需要 `source_tier`、`pub_time`、`actual_vs_expected`；目前
  `surprise` 多为 unknown，需人工补。
- 风格/行业测试资产：本地指数/行业数据可用，但需 PIT 口径和成本假设。

## 7. 采用规则

1. 任何 A/B 层结论先写成事件条件，再谈回测；不能写成条件的只作背景。
2. 外部事件先过闸门十九（T+1 开盘、拆 gap/intraday、成本、对照）。
3. MDE/OOS/多重检验台账；OOS 只用一次。
4. 通过后也只影响 regime/风格/仓位背景；个股买卖仍走既有策略/风控。
5. 没有事件就写“无重大事件”，不能省略；台账停滞由健康行告警。
