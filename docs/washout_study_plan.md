# 个股研究：庄家洗盘叙事 → 可观测模块（2026-10-25）

> 用户提出："为什么庄家拉升前非得洗盘？散户死扛不交筹码，庄家会一直洗吗？"
> 本文把这个叙事拆成**可观测的代理指标**，落成个股研究模块
> （`scripts/chip_structure.py` + `personal_daily_analysis.py` Part C），
> 并给出历史检验的预注册（N=79）。**不是买卖信号，不进 QMT 信号链。**

## 1. 叙事拆解：哪句能测、哪句不能测

| 叙事主张 | 可观测代理 | 数据 | 诚实结论 |
|---|---|---|---|
| 庄家底仓占流通盘 30–50% | 筹码集中度（90% 成本带宽度）、股东户数、十大流通股东 | 日线近似；`cyq-perf` 仅近 20 日；`holder-number` 需 PRO | **不可直接观测**。现代 A 股 5% 权益披露、30% 要约线，"单账户持 30–50% 流通盘"不可能合法隐身；能看到的只是**集中度代理** |
| 洗盘让不坚定筹码换手 | 洗盘期累积流通换手 ≥30% | 本地日线 + `stock_value_em` 流通股本（2018+） | **可测**（代理口径） |
| 洗盘时间 ≤3 个月 | 距前期高点 10–60 交易日 | 本地日线 | **可测**；"横盘超 3 个月=出货或快拉"不可分辨，模块标 `OVER_3M` |
| 拉升前要"看大盘脸色" | CSI800 收盘 vs MA200 | 本地指数 | **可测**（2026-10-23 为 MA200 下方 → 候选也不给 watch） |
| 洗盘压低拉升成本 | 区间/回撤/缩量形态 | 本地日线 | 可描述，不能证明"成本"动机 |
| 1 亿资金年化 10%，一个月利息 80 多万 | 算术：1e8×10%/12 = 83.3 万 | — | **算术对**；但资金成本不是可交易信号 |
| "死扛不交筹码，庄家会一直洗" | 换手不足/时间超限 → 状态机不成立 | — | 叙事上合理；**可检验的是"换手不足的事件后续更差吗"**（子组，见预注册 §7） |

**关键立场**：我们检验的是**形态 → 后续收益**，不是"庄家行为"。
即使形态有效，也不能证明叙事机制；形态无效，也不能证明"庄家不存在"。
这与项目已有结论一致：排序轴（动量/成交额/波动率）不是 alpha；能留下来的
必须是**制度/结构**解释（筹码换手后的抛压下降），否则默认 FAIL。

## 2. 模块定义（`scripts/chip_structure.py`）

参数集中在 `P`，历史研究引用同一组（改参数 = 新预注册）：

| 参数 | 值 |
|---|---|
| 前期窗口 / 拉升下限 | 250 交易日 / ≥30% |
| 距高点 | 10–60 交易日 |
| 回调 / 区间宽度 | −8%~−30% / ≤25% |
| 洗盘期累积流通换手 | ≥30% |
| 筹码窗口 / 半衰期 / 分箱 | 120 / 60 / 60 |
| 缩量参考 | 近 10 日均量 ÷ 前 40 日均量 |

**筹码分布代理**：把每个交易日的成交量按 `[low, high]` 均匀铺到价格分箱，
按 60 日半衰期衰减（越近的成交越代表当前筹码），得到
`cost_5/15/50/85/95`、`winner_rate`（现价以下的筹码占比）、
`width90=(cost_95−cost_5)/cost_50`。

**状态机**（顺序固定）：

```
PRIOR_LEG_MISSING → JUST_HIGH → BROKEN → OVER_3M → RANGE_TOO_WIDE
→ FLOAT_UNAVAILABLE → TURNOVER_LOW → WASHOUT_WATCH
```

- `WASHOUT_WATCH` 只代表**形态齐全**；`watch=True` 还要求
  `regime_ok`（CSI800 ≥ MA200，用户"看大盘脸色"）。
- `OVER_3M` 明确表示"出货/蓄势不可分辨"，不假装能区分。
- `FLOAT_UNAVAILABLE` 是**显式降级**（闸门十二），不静默当"无结构"。
- ETF 走 `ETF_NOT_APPLICABLE`（无流通股本/庄家筹码概念）。

## 3. 用法

```bash
# 单票/多票（asof 必须显式给，避免用未来 bar）
python scripts/chip_structure.py --codes 600276,601899 --asof 2026-10-23

# 个人持仓（默认读 config/my_holdings.csv）
python scripts/chip_structure.py

# 个人持仓日报（Part C 自动附带）
python scripts/personal_daily_analysis.py
```

输出：终端表 + `logs/chip_structure_<asof>.json`（含 `as_of`、参数、每票全部原始
数值与原因，可复算）。2026-10-23 样例：603259、300765 为 `WASHOUT_WATCH`，
但 CSI800 在 MA200 下方 → 均 `watch=False`；个人 11 只持仓无 `WASHOUT_WATCH`。

## 4. 数据可行性（2026-10-25 实测）

| 数据 | 状态 | 用途 |
|---|---|---|
| 本地日线（2014+，qfq；volume=万股 / amount=万元） | ✅ | 形态、换手、筹码代理 |
| `stock_value_em` 流通股本（2018-01-02 起，0.7s/票） | ✅ | 换手分母；缓存 `data_store/meta/float_shares/` |
| CSI800 PIT 权重（2019-01-31 起，92 快照，1335 只） | ✅ | 历史宇宙 |
| MCP `cyq-perf`（cost_5/15/50/85/95、winner_rate） | ⚠️ 仅最近 ≤20 交易日（FREE） | **只能前向核对**，不能回测 |
| MCP `holder-number` | ❌ 403 需 PRO | 股东户数（未来若升级） |
| akshare `stock_cyq_em` | ❌ 本服务器 RemoteDisconnected | 官方筹码历史（东财 IP 限制同族） |
| akshare `stock_zh_a_gdhs` | ❌ 全市场 888 页枚举超时 | 股东户数 |
| akshare `stock_zh_a_gdhs_detail_em` | 未测（同东财域，预期不稳） | 单票股东户数历史 |

→ **历史检验窗口只能 2019-02~2026-10**（PIT ∩ 流通股本史）；
筹码只能用日线近似；官方筹码/股东户数只能做前向。

## 5. 历史检验（预注册 N=79）

完整判据见 `logs/prereg_washout_20261025.md`，要点：

- **H-W1**：WASHOUT_WATCH 事件的 T+1 开盘 → T+60 收盘 CSI800 超额 > 0，
  同日 × 前期涨幅 × 流通市值固定效应后仍显著。
- **MDE 先行**：先 census（只数事件/事件月，不看收益）→
  MDE = 2.802×σ_month/√N_months（配对差；σ_month=5% 先验，N_months 按
  OOS 事件月计；另报 30% 个股 σ 的超保守上界，不作判定）；
  **MDE 锁定后才跑收益**。
- **IS 2019-02~2022-12 / OOS 2023-01~2026-10 只用一次**；
  PASS 只进个人观察清单，不进 QMT、不做组合 overlay。
- **子组只描述**：大盘脸色、换手阈值、3 个月分水岭、筹码温度——不参与判定。
- **盲区**：幸存者、季度 PIT、日线筹码、庄家不可观测、2019+ 仅 ~1.5 轮牛熊。

## 6. 与个人三层漏斗的关系

现有个人选股纪律：**成交额 TOP30 池 → 多维过滤过热 → 回调到 MA10 附近**。
洗盘模块插在**第 2.5 层（观察）**：

- 不改池子、不改过热过滤、不改买入触发；
- 只在候选票上多一行"洗盘候选 / 出货嫌疑 / 不适用"的**上下文**；
- `watch=True` 也只表示"形态齐全且大盘配合"，**不是买入理由**；
- 与 `max_vol20`（有 A/B 证据的风险过滤）不互相替代：拥挤度是**风险**，
  洗盘是**形态**，后者目前**零证据**。
