## 策略A-2 核心参数（生产版）

```
因子：多周期行业内Z-score
  1M动量(30%) + 6M动量(40%) + 12M动量(30%)
  × 量价突破加成（最高+50%）
  × 波动率倒数（0.7-1.3倍）
  × 成交额权重（截面70% + 行业内30%）

选股：行业均衡（按行业强度分配名额，单行业上限8只）
权重：得分线性加权 × 主线板块1.3倍
仓位：CSI800/MA200 五档（30%-100%，不完全清仓）
止损：期内-15% / 追踪-18%
调仓：每月月中+月末（约双周一次）
股票池：CSI800（800只）
```
