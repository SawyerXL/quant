```

  1M动量(30%) + 6M动量(40%) + 12M动量(30%)
  × 量价突破加成（最高+50%）
  × 波动率倒数（0.7-1.3倍）
  × 成交额权重（截面70% + 行业内30%）

      新仓保护期：持仓<2期的股票需替换者高出15%得分才能换出
权重：得分线性加权 × 主线板块1.3倍
仓位：CSI800/MA200 五档（30%-100%，不完全清仓）
止损：期内-15% / 追踪-18%
调仓：双周（月中+月末，约20次/年）
股票池：CSI800（800只）
```

**保护期设计依据（持仓天数分析）**
```
<2周   胜率23%  单笔期望-4.3%  ← 负收益，需减少
2-4周  胜率33%  单笔期望-3.2%  ← 负收益，需减少
>4周   胜率51%  单笔期望+6.0%  ← 正收益，需增加
→ 保护期让持仓向>4周偏移，提升期望收益
```
