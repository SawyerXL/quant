# 期权三级仿真：执行清单（2026-11-01）

> 客户经理要求做三级仿真交易 → **以国金最新认定规则为准**。本文只做执行清单
> 与记录模板，不替代券商适当性审核；仿真不等于实盘权限，实盘也不等于 QMT API。

## 1. 先向客户经理确认（逐条问清）

1. 三级仿真要求：**多少交易日、多少笔、哪些策略/行权记录**？
2. 三级仿真记录能否**同时认定一级、二级**？还是必须先开一级、隔一段时间再开二级/三级？
3. `F:\fzqq` 仿真期权客户端是否被国金认可？记录如何核验（截图/流水/行权/结算单）？
4. 资产 **50 万 / 20 个交易日日均**、**6 个月**证券经验、期权考试、风险测评是否都满足？
5. 真实期权账户与 QMT 实盘资金账号是否同一个？**期权权限与 QMT mini/API 权限是两套审批**。
6. 三级是否包含**卖出开仓/保证金/裸露卖权**？仿真里做哪些算数？

## 2. 仿真练习建议（目标是“记录合规”，不是赚钱）

- 标的：流动性最好的 `510050` / `510300`，近月或下月合约；小单量。
- 按客户经理给的策略清单逐项做，不追求盈亏；不要为了“好看”重仓赌方向。
- 每笔记录：日期、标的、合约、策略、开/平、方向、价格、数量、权利金、
  保证金、盈亏、截图/流水、备注。
- 每日保存：仿真账户截图、委托/成交/持仓/行权记录；按日期归档。
- 若三级要求“卖出开仓”，只在**仿真**里做；实盘项目**不做裸卖**。

## 3. 策略覆盖（以国金清单为准，不要自行推断）

- 一级常见：买入认购/认沽、备兑开仓、保护性认沽等。
- 二级常见：牛市/熊市价差、跨式/宽跨式等。
- 三级常见：卖出开仓/保证金策略等。
- **以客户经理给的清单打勾**；不同券商/交易所口径可能不同。

## 5. 项目红线（实盘）

- 项目只做**保护性 Put / 价差**，Level 1/2 足够；
- **不做裸露卖权**（无限风险，违反风控红线）；
- Put 对冲回测 2015-2026 全程对冲 **−6.11%** vs 裸 **+1.77%**，期权只当
  极端尾部保险，不是赚钱引擎；
- 实盘期权权限 ≠ QMT mini/API 权限；QMT 实盘仍卡在 mini/API 权限，两件事分开推进。
