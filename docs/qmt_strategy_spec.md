# QMT 主策略完整说明（v2.1，2026-08-30）

> 本文档由 2026-08-30 审计+回测后整理，作为主策略唯一权威口径。
> 所有参数改动必须回测 A/B 对比 + 用户确认（CLAUDE.md 工程纪律）。

## 1. 一句话定位

**成交额 TOP30 等权动量池 + MA200 择时控仓 + MA10 退出纪律 + 拥挤度过滤。**
熊市赚"少亏+反弹回血"，牛市赚"动量+弹性"。没有做空，没有绝对收益机制。

## 2. 核心机制（逐项）

### 2.1 股票池：成交额 TOP30
- 取最近 20 个交易日平均成交额前 30 名
- 本质：永远持有"当下资金最聚集"的票
- 优点：熊市反弹日弹性大（8 月池子等权 +12.9% vs 上证 +1.6%）
- 代价：动量拥挤——8/19 型跌停潮首当其冲（见 2.5）

### 2.2 择时控仓：CSI800 / MA200 五档
| 指数/MA200 | 仓位 | 状态 |
|---|---|---|
| ≥1.05 | 100% | 强牛 |
| 1.02~1.05 | 85% | 牛 |
| 0.98~1.02 | 70% | 震荡 |
| 0.95~0.98 | 50% | 弱 |
| <0.95 | 30% | 熊（不清零，防踏空V反） |

- 调仓日生效；仓位≤30% 时清仓观望
- 8 月实测：平均仓位 47%，8/19 跌停潮只伤净值 -1.4%（而非满仓 -3.1%）

### 2.3 退出纪律：MA10-4d
- 单票连续 4 个交易日收盘在 MA10 下方 → 清仓
- 双周调仓时自动补买新池子票
- 作用：单票层面截断持续走弱（8 月 QMT 单票未出现万泰式 -68% 事故）

### 2.4 止盈：TP30/60（诚实标注：装饰性）
- 规则：浮盈 +30% 卖 1/3，+60% 再卖 1/3
- 2026-08-29 复验结论：**在现口径下从未改变任何一笔交易**（票在 +30% 前就被调仓/MA10 换掉）。保留为状态机字段，不影响结果
- 与 stop_monitor v3 原结论（+0.9pp）冲突，复验未复现 → 按纪律降级"未验证"

### 2.5 拥挤度过滤（v2.1 新增，2026-08-30）
- 调仓时剔除**20 日波动率 >5%** 的票（只用 T-1 及以前数据计算）
- 动机：8/19 失血归因——9 只跌停凶手事前波动率 4.4~7.9%，而同期防御票 1.0~1.7%；凶手 20 日涨幅仅 +2~15%，涨幅过滤拦不住
- 四窗口 A/B（用户要求反复确认后合入）：
  | 窗口 | 基线 | +过滤 | 差 |
  |---|---|---|---|
  | 2019-2022 | +8.86% | +11.23% | +2.4pp |
  | 全期 2019-2026.8 | +5.10% | +6.92% | +1.8pp |
  | 近段 2022-2026.8 | +3.87% | +5.24% | +1.4pp |
  | 近段 2024.7-2026.8 | +11.30% | +16.65% | +5.4pp |
- 稳健性：阈值网格 4~6% 平滑平台；严格口径（不含当日）与含当日差 +0.19pp

### 2.6 止损：成本 -15% 全卖（V2）
- 由 Windows 端 stop_monitor 执行（20 分钟心跳 `--go`）
- 追踪止损已停用（2026-07-09 A/B：追踪只砍赢家、对回撤零贡献）

## 4. 执行链（数据流）

```
Windows QMT (仅执行)                       Linux 服务器 (研究/信号)
  ├─ 15:10 每日持仓快照(修复目标, 现状飘09:15~16:58) ──┐
  ├─ 调仓指令: buy/sell 增量(非幂等, 非调仓日清空)       │
  └─ stop_monitor 20分钟心跳(--go, 成本-15%全卖)        │
                                                  ↓
                                            qmt_nav_track.py
                                            (100万notional口径,
                                             快照价仅采信≥15:00,
                                             否则本地收盘价重估)
                                                  ↓
                                            logs/qmt_nav_history.parquet
```

## 5. 风控红线（CLAUDE.md 强制）
- 单票仓位上限（Track A 口径）、单笔订单 5 万、涨停禁买/跌停禁卖
- 账户回撤熔断 25%
- 所有订单过 `execution/risk.py` 的 `risk_check()`

## 6. 历史验证

**回测**（TOP60 口径，2019-2026.8）：全期年化 +5.1%（+过滤 +6.9%），夏普 0.31（+过滤 0.49），回撤 -27.1%。年度：2020 +26.6%、2025 +40.3%、2022/2023 亏损（熊市防守年）。

**8 月实盘**（100 万 notional，收盘价重估口径）：7/20→8/28 **+3.78%**，夏普 2.11，回撤 -4.26%，平均仓位 47%。同期上证 -0.09%、中证800 -3.54%。
- 峰值 8/17 +7.05 万 → 收尾 +3.78 万，失血主因 8/19 单日 -3.1%（9 只持仓跌停）
- 诚实对照：8/3 持仓满仓死拿 +12.9%，策略只兑现 +6.6%——纪律成本 6.3pp，买的是"躲开下一次 8/19 是趋势起点"

## 7. 已知问题 / 待办

1. **pool_size 不一致**：实盘 TOP30 vs 回测 DEFAULT TOP60。需 A/B 定口径后统一
2. **Windows 快照时点飘移**：09:15~16:58 都有，Linux 侧已有重估防御，根治需登 Windows 改计划任务（隧道待恢复）
3. **做T增厚**：t0 开关保持关——验证期（9/23 满月）目前 53.8% 胜率/-0.99% 不达标
4. 止盈开关（TP30/60）与"无止盈"回测逐位相同——装饰性，不构成收益来源
