# A股走势长期研究章程（2026-10-16 立项）

> 目标：日度学习/分析 A 股走势，建立**可计分**的预测能力；只有在技能被
> 证明后，才允许把预测接进盈利路径（且必须走既有闸门）。

## 1. 已知边界（本项目自有证据，先于任何新假设）

- **方向接近抛硬币**：2018-2026 上证次日上涨占比 51.7%、5 日 52.2%；
  MA200 下方时次日上涨仅 48.5%（n=743）；前 5 日跌 >3% 后次日上涨
  57.3%（n=171）。方向优势必须靠证据，不靠叙事。
- **波动聚集是唯一强可预测结构**：大波动日次日再大波动 2.59×（8.4%→
  21.8%）。"还会大动"可预测，"往哪动"不可预测。
- **18 因子两轮已测完**（docs 因子预测力全景）：次日上证只有美股三指数/
  铜/涨停情绪有预测力，且主体在跳空里（不可执行）；其余为噪音。
  新研究不得重复已判死方向。
- 外部研报事件类 alpha 默认不可执行（跳空 + price in），需先过闸门十九。

## 2. 每日流程

| 时点 | 动作 | 方式 |
|---|---|---|
| 18:15（交易日） | 快照 `scripts/market_daily_study.py` → `logs/market_daily_study.csv` | cron 自动 |
| 18:20（交易日） | 状态预测 `scripts/market_state_forecast.py`：登记次日 \|上证收益\| ≥1% / ≥1.5% 概率 → `logs/state_forecast_ledger.csv`；同时结算前一交易日 | cron 自动 |
| 18:25（交易日） | 方向台账机评 `scripts/prediction_ledger.py` → `logs/prediction_score.json` | cron 自动 |
| 盘后 | 阅读快照 + 分析（宽度/波动/位置/情绪） | 人工/会话 |
| 次日 09:30 前 | 登记方向预测 `scripts/prediction_ledger.py register` | 会话 |
| 目标日收盘后 | 结算 `prediction_ledger.py score`，月度 `report` | 会话 |

## 3. 预测登记规则（事前锁）

1. 预测必须在目标交易日 **09:30 前**登记；`registered_at` 晚于目标开盘
   标 `late`，不计入技能评估（防事后）。
2. 登记后不可修改；确需更正=新登记一条（旧的保留）。
3. 必填：p_up（概率）、direction、confidence、rationale（机制/证据）、
   features（当次快照关键值）；features_hash 自动生成。
4. **没有优势时登记基准率**（regime 条件化），不许为了"像个预测"编方向。

## 4. 评分与判据

- Brier = mean((p_up − outcome)²)，对照三个基线：历史基准率常值、0.5 常值、
  MA200 regime 规则。
- 月度报告 `prediction_score.json`；季度复盘。
- **技能成立门槛（出数前锁）**：≥60 条有效预测 且 Brier 优于基准率基线
  的幅度 > 1×SE（SE 用配对差分的样本标准误）且方向命中率 > 基准 + 1×SE。
  未达标 → 只记录，不改任何交易。
- **状态预测轨道（2026-10-22 起）**：目标不是方向，而是"次日波动幅度"
  （`abs_ret ≥ 1% / 1.5%`），依据是已知的波动聚集结构。条件基准率三档：
  C1 大波动日（今日 |ret|≥1%）、C2 vol20 当前值 ±2.5pp 档、C3 MA200 距离
  ±2pp 档；按 C1→C2→C3 取第一个样本 ≥200 的条件，都没有则用无条件基准。
  预测概率=条件历史频率。18:20 收盘后登记（当日收盘已知，无前视），
  次日 18:20 自动结算。
  技能判据同上：**每个事件 ≥60 条已评分且 Brier 优于基准率 >1×SE**
  才谈接入；接入方向只可能是仓位/风险预算（不做方向下注），且仍须过
  新假设与参数三件套。台账 `logs/state_forecast_ledger.csv`，汇总
  `logs/market_state_forecast.json`；18:40 健康行 `research_track` 可见
  （停滞/缺失进 alerts）。

## 5. 盈利接入规则

- 预测**不得直接改信号链**（架构原则）；任何策略变更走参数三件套
  （预测登记→判读矩阵→归因闸门）与新假设预算。
- 本日常研究本身是**测量计划**，不消耗年度新假设预算；由它派生的任何
  交易规则按一个假设计。
- 任何接入前必须回答：可执行价（T 收盘→T+1 开盘拆 gap/intraday）、成本、
  样本量、失败模式。

## 6. 三层预测纪律（2026-10-26 用户要求）

每日/阶段预测必须同时覆盖三层，缺一层即视为不完整：

### 6.1 三层定义

| 层 | 内容 | 作用 | 时间尺度 |
|---|---|---|---|
| **A. 国家战略/金融战略** | 会议/文件、货币政策、财政、资本市场制度、汇率、外部战略 | regime、风格、仓位背景 | 月/季 |
| **B. 消息面事件** | 当日政策/监管/外部/产业事件 | 事件驱动、跳空/5日窗口 | 日/周 |
| **C. 市场结构** | 技术、广度、波动、资金、基准率 | 当日方向/波动分布 | 日 |

**A 层不直接给日内方向；B 层必须落成可回测条件；C 层是基准分布。**
三层结论不一致时，以“可回测、可执行”的那一层为准；不能回测的叙事只能
作背景。

### 6.2 B 层：消息面事件的可回测条件模板

每个事件必须写成一行结构化记录（`scripts/news_event_ledger.py` 产候选，
人工复核后才可进入研究）：

| 字段 | 要求 |
|---|---|
| `event_id` | 标题+时间+来源 hash，防重复 |
| `pub_time` | 新闻/公告的**原始发布时间**，不是抓取时间 |
| `source` / `source_tier` | 官方（新华社/国务院/央行/证监会/财政部/发改委/统计局）/主流媒体/公司公告/外媒 |
| `category` / `subcategory` | 国家战略/金融战略/货币/财政/资本市场/产业/外部/监管/公司 |
| `direction` | +/−/neutral；必须写依据，不能只凭标题 |
| `surprise` | 实际 vs 预期（如降准 50bp vs 0；无预期则标 unknown） |
| `scope` | 全市场/风格/行业/个股 |
| `entry_rule` | **T+1 开盘**（默认）；盘中发布会类才允许盘中；拆 gap/intraday |
| `horizon_d` | 1/5/20（政策底默认 5 日）；长期战略 60/120 |
| `exit_rule` | 固定期限；不引入事后止损 |
| `control` | 同 regime 非事件日/匹配组合 |
| `sample_n` / `mde` / `oos` | 出数前锁定；OOS 只用一次 |
| `status` | candidate / reviewed / registered / closed |

- **无重大事件也必须留一行**：`event_id=no_material_event`，
  `material=0`；不能把“没消息”省略成空白天。
- 只有 `status=registered` 且通过闸门十九/MDE/OOS 的事件，才允许进入
  预测或仓位；candidate 只作研究。
- 事件日期落非交易日→首个交易日；公告在盘中→按盘中事件单列，不混用
  隔夜事件。

### 6.3 A 层：国家战略/金融战略的可回测代理

| 主题 | 事件代理（示例） | 测试资产 | 期限 |
|---|---|---|---|
| 科技自立/新质生产力 | 国务院/部委文件、五年规划、大基金 | 科创50/半导体 vs 沪深300 | 20/60d |
| 安全/军工/能源 | 国防预算、能源安全文件、地缘事件 | 军工/能源 vs 宽基 | 5/20d |
| 扩内需/消费 | 促消费文件、以旧换新、消费券 | 消费 vs 宽基 | 20/60d |
| 化债/地产 | 化债额度、地产政策、专项借款 | 银行/建筑/地产 | 20/60d |
| 资本市场改革 | 新“国九条”、中长期资金、汇金增持、IPO/减持规则 | 券商/沪深300 | 5/20d |
| 货币/财政 | 降准降息、MLF/OMO、社融、专项债/特别国债 | SH/CSI800/债 | 5/20d |
| 汇率/外部 | USDCNY、Fed、关税、制裁、油价/中东 | A股 gap/intraday | 1/5d |

- A 层事件同样是**事件研究**，不是叙事：预登记、T+1 开盘、对照、
  MDE、OOS；样本通常很小，**功效不足就只作背景**，不得部署。
- 已有结论直接复用：降准 20 日 +2.86%（n=27，牛市更强）；政策利好日
  不追开盘（跳空占大头）；外部冲击盘中继续定价、20 日方向由 regime 决定。
- A 层输出只允许影响 **regime/风格/仓位背景**；不能单独触发个股买卖。

### 6.4 日常流程（补充）

| 时点 | 动作 |
|---|---|
| 22:35 | `news_capture.py` 抓 CCTV/全球快讯 |
| 22:40 后 | `news_event_ledger.py` 产当日候选事件（只读，候选非信号） |
| 次日 09:03 | 盘前检查把隔夜外盘/消息映射为**跳空提示**，不改收盘方向 |
| 09:30 前 | 预测卡必须含 A/B/C 三层；B 层无事件写“无重大事件” |

### 6.5 禁止事项（新增）

- 用“国家战略/消息面”叙事替代可回测事件条件；
- 只写“利好/利空”不写时间戳、来源、意外度、入场价、期限、对照；
- 把公司新闻/个股公告混入宏观预测；
- 事后从新闻里挑选能解释当天走势的标题（叙事偏差）；
- 未过闸门十九/MDE/OOS 就按消息面调仓。

### 6.6 外围消息/隔夜映射（2026-10-26 用户要求）

**09:03 盘前必须记录以下快照（`preopen_check.py` / `overnight_market`）**：

| 维度 | 字段 |
|---|---|
| 美股 | 标普/纳指/道指收盘（或 live 盘中，标注 as_of） |
| 利率/汇率 | 美债10Y、美元指数、USDCNH/离岸人民币 |
| 商品 | 油价（WTI/Brent）、LME 铜、黄金 |
| 亚太/离岸 | 日经、恒生、A50 期货、FXI/KWEB/ASHR |
| 隔夜新闻 | Fed/关税/制裁/地缘/中美/OPEC/非农/CPI 等 material headline |

**映射规则**：

1. 外围信号**只改跳空**，不改收盘方向；历史证据：外盘信号主要落在
   gap，盘中≈抛硬币（既有 18 因子/外盘研究）。
2. 必须拆 `gap_ret = open/prev_close−1` 与 `intraday_ret = close/open−1`；
   不得用全天收益把 gap 和盘中混在一起。
3. 只有已通过闸门十九/MDE/OOS 的外围事件，才可进入仓位；否则只写
   “gap 提示/风险背景”。
4. 未来事件（Fed/关税/OPEC/非农）**不预埋**；等事件发生，按 T+1 开盘
   入场做条件评估。
5. `live` 盘中快照必须标 `as_of`，不能当收盘；09:03 的收盘快照才可
   用于次日预测的正式记录。

**可回测外围事件 schema（补充）**：
`event_time/source/category(US_index|Fed|tariff|sanction|oil|USDCNH|Asia)/
actual_vs_expected/scope/entry=T+1_open/horizon_d=1,5/gap_ret/intraday_ret/
control/MDE/OOS/status`。历史已有结论（美股→A股主要 gap、恒生零预测力、
铜/金开盘操作降级）直接复用，不重复判死。

## 7. 禁止事项

- 事后修改预测或挑选有利样本复盘
- 用外部观点/叙事替代数据证据
- 以"看对了一天"推断"有能力"
- 让预测绕过风控红线或冻结协议
